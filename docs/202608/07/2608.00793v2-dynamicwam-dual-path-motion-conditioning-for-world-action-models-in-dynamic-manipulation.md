## 摘要
动态操作要求机器人推断目标运动并及时响应，然而现有的世界-动作模型（WAMs）通常仅以当前帧为条件，并同步执行大型骨干网络，这限制了动态场景中的运动感知和响应控制。我们提出了DynamicWAM，一种用于动态物体操作的紧凑型WAM，采用双路径运动条件化。DynamicWAM引入了历史流条件化，通过冻结的预训练视频VAE，将时间对齐的光流帧与当前观察一起编码，以保留空间运动结构，同时将位移、持续时间、速度和加速度的运动学描述符注入到动作专家中，以提供运动幅度和时间。这两条互补路径通过联合世界-动作注意力进行融合。蒸馏的紧凑骨干和基于实时分块（RTC）的异步执行进一步实现了响应控制。在DOMINO上，DynamicWAM实现了38.2%的成功率和53.2的操作分数，优于所有评估的基线。在涵盖线性、圆形和复合目标运动的12个真实世界任务中，它达到了46.7%的平均成功率，超过最强基线22.9个百分点。

## Abstract
Dynamic manipulation requires robots to infer target motion and respond promptly, yet existing World-Action Models (WAMs) typically condition only on the current frame and execute large backbones synchronously, limiting motion awareness and responsive control in dynamic scenes. We propose DynamicWAM, a compact WAM for dynamic object manipulation with dual-path motion conditioning. DynamicWAM introduces history-flow conditioning, encoding temporally aligned optical-flow frames alongside the current observation through a frozen pretrained video VAE to preserve spatial motion structure, while injecting kinematic descriptors of displacement, duration, velocity, and acceleration into the action expert to provide motion magnitude and timing. The two complementary paths are fused through joint world-action attention. A distilled compact backbone and real-time chunking (RTC)-based asynchronous execution further enable responsive control. On DOMINO, DynamicWAM achieves a 38.2% success rate and a 53.2 manipulation score, outperforming all evaluated baselines. Across 12 real-world tasks spanning linear, circular, and compound target motion, it achieves a 46.7% average success rate, exceeding the strongest baseline by 22.9 percentage points.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究场景**：机器人在动态环境中进行操作，目标物体在推理和动作执行期间持续运动（如传送带上的物体、旋转转台上的物体、沿曲线运动的玩具等）。
- **现有方法的缺陷**：
  - 主流世界-动作模型（WAMs）通常**仅以当前帧**作为条件，无法感知目标的运动状态和趋势；
  - 核心骨干网络**同步执行**导致推理延迟暴露在执行链路中，预测结果在动作执行前就已"过时"；
  - 光学流虽然能描述运动空间结构，但其渲染通常采用**逐帧幅值归一化**，丢失了全局位移尺度；且渲染图像不包含帧间时间间隔，因此无法恢复目标的速度信息。
- **核心问题**：如何在视觉上相似的当前观测对应不同目标运动（如相同位置但方向相反）时，让模型准确判别运动并生成相应的接触动作？如何在不改变机器人动作空间的前提下把运动信息注入世界-动作模型？
- **核心含义**：动态操作的成功既需要**运动感知（motion awareness）**也需要**响应速度（responsiveness）**，二者缺一不可，必须同时解决。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想
DynamicWAM 提出**双路径运动条件化（Dual-Path Motion Conditioning）**：
- **路径一（历史流）**：为视频预测提供密集的空间运动结构；
- **路径二（运动学token）**：为动作生成提供运动幅值和时序信息。

两条路径通过**联合世界-动作注意力**融合，既不影响机器人动作空间，也无需引入额外运动编码器。

### 关键技术细节

**（1）历史流条件（History-Flow Conditioning）——空间运动结构**

- 在每个动作块边界 t，将观测历史划分为 K=4 个区间，相邻端点间隔 ∆=4 个策略步长：  
  `nk = t − (K−k)∆`
- 对每个区间，用 Farnebäck 稠密光流算法计算固定头部相机的前向光流，并进行**前向-后向一致性校验**，得到掩蔽光流场 Ûk。
- 每个光流场渲染为 RGB 图像 Rk：方向映射为色相，幅值以帧内 99 分位数归一化：  
  `rk(p) = min(‖Ûk(p)‖₂ / q(Ûk), 1)`
- 渲染光流序列与当前观测沿时间轴拼接，送人**冻结的预训练视频VAE**编码：  
  `Zct = E_VAE([R1,...,R_K, Ot])`  
  从而使运动信息与外观信息共享同一潜空间路径，无需额外编码器。

**（2）运动学token条件（Kinematic Token Conditioning）——运动幅度与时序**

- 为弥补光流渲染丢失的尺度/时序信息，对每个区间计算 12 维运动学描述符 mk，包括：
  - 平均位移 dk、平均位移幅值 d̄k、99 百分位位移 d99_k；
  - 区间时长 Δτk；
  - 速度统计量 vk、v̄k、v99_k（由位移除以时长得到）；
  - 加速度 ak 和加速度幅值 ‖ak‖₂。
- 描述符经数据级标准化、两层 MLP 投影、加区间位置/类型嵌入，得到运动学 token e1,...,eK，注入动作专家流形：
  `Xa = [es(st); ea(Aσa_t); e1,...,eK; g1,...,g4]`
- 动作解码器只读取原始状态-动作 token，因此**机器人动作空间完全不变**。

**（3）联合训练目标**

- 视觉和动作两组流都用条件流匹配（Conditional Flow Matching）训练：
  `xσ = (1−σ)x + σϵ, u* = ϵ − x`
- 联合目标：
  `L = E[‖ûa − u*a‖₂²] + λv E[‖ûv − u*v‖₂²]`
- 三阶段训练：
  1. **Stage 1**：视频专家蒸馏（80k步）——从 Wan2.2-TI2V-5B 蒸馏出 12 层紧凑视频专家，含真值流匹配 + 隐状态蒸馏 + 运动蒸馏三种目标；
  2. **Stage 2**：动作专家预训练（80k步）——冻结视频专家，只训练动作专家和运动学token模块；
  3. **Stage 3**：联合微调（40k步）——联合优化动作与视频流损失，λv 从 0.01 退火到 0.001。

**（4）RTC 异步执行**

- 真实部署采用 Real-Time Chunking（RTC）：在当前动作块执行期间异步预测下一动作块，并通过引导权重平滑合并连续动作块；
- 推理加速：视频分支 KV 缓存复用，仅在第 0、1 步做完整视频前向，后续步骤只更新动作 token，延迟从约 550ms 降至 173.7ms；
- DOMINO 评测中为公平对比，**故意禁用 RTC**，保持基准原生同步协议。

## 6. 主要结论与发现

1. **双路径运动条件化显著提升动态操作性能**：在 DOMINO 上，从静态 WAM 的 22.7% SR 提升到完整模型的 38.2% SR，MS 从 38.3 提升到 53.2，全面超越所有基线（最强基线 InternVLA-A1.5 为 29.3% SR / 42.5 MS）。
2. **两条路径互补而非冗余**：历史流单独带来 +4.5 SR，运动学token单独带来 +7.8 SR，两者组合额外获得 +7.7 SR（相对更强单路径），证明二者分别编码了互补的运动信息。
3. **真实世界有效性**：12 任务平均成功率 46.7%，超过最强外部基线 π0.5（23.75%）22.92 个百分点；L3 复合运动任务上外部基线全部失败，而 DynamicWAM 达到 18.75%。
4. **RTC 提供独立增益**：在完整模型基础上，RTC 额外提升 4.59 个百分点，且 L3 上增益最大（+6.25），说明执行-推理重叠在复杂运动场景中更有价值。
5. **运动感知能补偿推理延迟**：DynamicWAM 虽单次推理延迟（173.7ms）与 InternVLA-A1.5（158.4ms）相当，但由于历史流提供了运动轨迹证据，能在目标持续运动情况下部分补偿推理期间的目标位移。
6. **视觉泛化以 ID 能力为基础**：DynamicWAM 在分布外场景下的优势主要来自更强的分布内表现，保留率（0.52）与其他方法（0.53-0.54）相近。

## 7. 优点与亮点

- **问题洞察深刻**：明确指出"相同的当前帧可能对应相反的运动方向"这一动态操作的根本歧义，并用图 1 做了清晰的直观说明。
- **方法设计巧妙**：
  - 复用冻结视频 VAE 编码光流，避免了额外运动编码器的参数开销和训练复杂度；
  - 光流渲染与运动学描述符从**同一掩蔽光流场**导出，两条路径天然对齐，信息互补且不引入不一致的中间表示；
  - 注入动作专家而不改变动作空间，使模型可以无缝替换现有 WAM 政策；
  - 通过 RTC 将推理延迟从执行关键路径上移除。
- **蒸馏工程完备**：三目标蒸馏（真值流匹配 + 隐状态蒸馏 + 运动蒸馏）设计精细，蒸馏头权重逐步退火，体现工程深度。
- **实验分析深入**：t-SNE 可视化验证了冻结VAE保留运动结构；注意力可视化展示了运动学token对观测网格的注意偏向；失败模式量化归因清晰。
- **消融设计严格**：w/o flow 用黑帧填充而非直接减少输入通道，排除输入几何变化带来的混淆变量。
- **比较公平**：DOMINO 评测统一采用带原生同步协议，排除 RTC 影响；所有基线在匹配数据预算下用官方流程微调；在 main table 中如实报告延迟而非只报性能。

## 8. 不足与局限

- **论文自述局限**：
  - 依赖**二维图像空间运动**（来自固定外部相机），无法充分利用三维运动信息；
  - **未显式区分指令指定的目标与其他运动区域**，在杂乱场景中易受干扰物、遮挡和视角变化影响。
- **实验局限**：
  - 真实世界每任务仅 20 次试验，**缺乏统计显著性报告**；
  - L3 外部基线成功率均为 0%，存在**地板效应**，无法清晰对比各方法在复合运动上的相对差异；
  - 视觉泛化实验仅覆盖 L1 任务，且未测试遮挡、视角变化等论文自述敏感场景；
  - 未报告跨硬件（不同夹爪/相机配置之间）的性能差异性分析。
- **方法局限**：
  - 光流计算本身依赖 Farnebäck 稠密光流，对快速运动、运动模糊和低纹理区域可能产生噪声或无效光流；
  - 运动学描述符是对整帧有效像素的**全局池化**统计，混合了目标运动与机器人自身运动的信息，无法精细区分二者；
  - 光流计算和渲染增加了单次策略查询的预处理延迟，这一部分算力在延迟数字中被包含但未单独拆解。
- **应用限制**：
  - 需要固定头部相机视角，对移动平台或视角变化适应性有限；
  - 距离/速度量纲依赖像素网格，跨相机内参迁移需重新校准或标准化；
  - 在目标速度过快、超出光流跟踪范围时性能衰减明显（如 L3 复杂任务仅 18.75%）。
