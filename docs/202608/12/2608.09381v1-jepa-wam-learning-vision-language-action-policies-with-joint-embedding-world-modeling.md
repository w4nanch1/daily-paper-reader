## 摘要
鲁棒的机器人控制受益于显式建模状态转移，但视频生成世界动作模型（WAM）引入了显著的部署成本。现有的潜在WAM避免了显式的未来生成，但常常压缩预测表示或将预测建模与用于动作生成的表示分离。我们引入了JEPA-WAM，一种在预训练V-JEPA空间中构建的潜在WAM，通过共享预测器将潜在转移预测与连续动作生成耦合在一起。JEPA-WAM预测一个空间结构的联合当前-未来目标，捕获当前与未来观测之间任务共享的视觉时间结构，同时保留密集的补丁级对应关系。通过共享预测器，转移监督直接塑造主干网络，从中提取专用表示用于动作预测。相同的设计也可以实例化到预训练的VLA策略中，同时保留其原始感知和动作通路。在LIBERO-Plus上，JEPA-WAM达到79.2%的准确率，无需大规模机器人策略预训练即取得最佳结果，而其预训练的π₀.₅实例化达到86.3%，实现了总体最佳性能。在RoboTwin 2.0和真实世界双臂操作上的实验进一步证明了在视觉和空间变化下的强泛化能力。

## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

## 2. 方法论

### 2.1 核心思想
- 使用冻结的预训练 **V-JEPA 2.1** 编码器定义视觉表示空间。
- 构造**空间结构化的联合当前–未来目标**（joint current–future target），捕获两帧之间的时间关系，同时保留密集 patch 级对应。
- 通过**共享预测器**（Qwen2.5-0.5B）同时执行：
  - 潜在转移预测：由视觉 token 位置的隐状态预测联合目标；
  - 动作生成条件提取：由专用 action placeholder 生成动作条件表示。
- 部署时丢弃目标分支与预测头，仅保留当前观测编码 + 预测器 + 动作专家，不增加推理负担。

### 2.2 关键技术细节
- **当前视觉表示**：
  - 对每个相机视角独立用冻结 V-JEPA 编码，按固定相机顺序拼接得到 \( Z_t \in \mathbb{R}^{N_{vis} \times d_J} \)。
- **联合当前–未来目标**：
  - 将当前帧 \(O_t^v\) 与未来帧 \(O_{t+\delta}^v\) 沿时间维堆叠后联合编码，得到 \( Y_{t,t+\delta} \)；
  - 得益于 V-JEPA 的时间 tubelet 大小为 2，两帧输入产生与单帧相同的空间 token 网格，保持 patch 对应。
  - 目标经过 stop-gradient，避免梯度回传至冻结编码器。
- **共享预测器与转移预测**：
  - 视觉表示经轻量投影器 \(P_{vis}\) 输入 Qwen，并加入 action placeholder；
  - 预测头 \(G_\phi\) 将视觉 token 位置的隐状态映射回 V-JEPA 空间：
    \[
    \hat{Y}_{t,t+\delta} = G_\phi(Q^{wm}_t)
    \]
  - 转移损失为 patch 级余弦距离：
    \[
    L_{wm} = \frac{1}{B N_{vis}} \sum_{b=1}^B \sum_{n=1}^{N_{vis}} \left(1 - \cos\left(\hat{Y}^{(b)}_{t,t+\delta,n}, Y^{(b)}_{t,t+\delta,n}\right)\right)
    \]
- **动作生成**：
  - 采用 DiT 动作专家，条件流匹配；
  - LIBERO 使用 velocity-prediction，RoboTwin 2.0 使用 x-prediction；
  - 总损失为 \(L = L_{act} + \lambda_{wm} L_{wm}\)，\(\lambda_{wm}=0.5\)。

### 2.3 向预训练 VLA 策略迁移
- 在预训练 π₀.₅ 中插入可学习的 future tokens，其输出隐状态经 reshape、投影和双线性上采样，与联合目标对齐；
- 保持原感知与动作通路不变，动作 token 不能注意新加入的 future-token queries；
- 辅助损失权重线性 warmup 至 0.1，不影响原策略结构。

## 7. 优点

- **设计创新**：用共享预测器统一转移预测与动作生成，使时间监督直接塑造动作相关主干，避免了“预测表征与动作表征割裂”的问题。
- **预测目标设计合理**：联合当前–未来目标而非绝对未来，保留密集 patch 级空间结构，不需要生成唯一未来帧，降低部署成本。
- **高效部署**：推理时不运行目标编码、转移预测头或未来帧生成，RoboTwin 上单次推理约 85 ms（11.76 Hz），优于 ABot-M0。
- **可迁移性**：同一监督方式可加在预训练 VLA 上并稳定提升 π₀.₅ 的 ID/OOD 性能，且不改动原动作通路。
- **实验严谨**：多基准、多消融、逐任务结果完整，并辅以冻结表征探针与置信区间，分析深入。

## 8. 不足与局限

- **语言条件缺失**：论文在 Limitations 中明确指出，联合目标主要捕获任务共享的视觉时间结构，当同一观测在不同指令下应产生显著不同转移时，监督可能不够表达。语言条件化或模态混合的转移目标是未来方向。
- **特定类别提升有限**：
  - 在 LIBERO-Plus 的 Lang（语言变化）类别上

在 LIBERO-Plus 的 Lang（语言变化）类别上提升相对有限，提示当同一观测在不同指令下需要产生本质不同的未来转移时，当前任务共享的视觉预测目标难以充分表达这种语义差异；论文将“语言条件化或模态混合的转移目标”列为未来方向，也印证了这一局限。
- **对预训练表征的依赖**：方法建立在 V-JEPA 表征空间之上，联合目标的质量上限受制于底层表征的时空语义丰富度；消融显示替换为 DINOv2+SigLIP 后 OOD 性能明显下降（73.2% vs. 77.0%），说明其结果对表征选择较为敏感，迁移到其他底模时未必同等有效。
- **训练成本与报告透明度**：虽然部署时零额外推理开销，但训练需对每对当前–未来帧额外编码，且共享预测器、转移预测头与动作专家联合训练；论文未提供 GPU 型号、总训练时长与能耗数据，降低了成本评估的可复制性。
- **时间间隔 δ 的敏感性**：转移预测依赖固定的帧间隔 δ，不同任务最佳 δ 可能不同；对需要长视界规划的任务，单步或短间隔的联合目标可能不足以刻画完整的因果结构。
- **真实世界评估规模有限**：每个任务仅 10 次 rollout，且仅 5 个任务、两类 OOD 变化，统计功效与场景覆盖仍显不足；个别任务上的提升可能受随机波动影响。
- **RoboTwin Random 绝对性能仍偏低**：即便 JEPA-WAM 在该基准上领先对比方法（36.9%），但绝对成功率仍不高，说明极端领域随机化下的鲁棒性仍有较大提升空间。

## 9. 综合评价

- **总体判断**：JEPA-WAM 以“冻结 V-JEPA 表征 + 联合当前–未来目标 + 共享预测器”的组合，为 VLA 策略提供了一种轻量、部署友好的显式时间预测监督方式。对“预测什么表征、如何与动作生成集成”两个关键问题给出了清晰且可迁移的回答，创新性与动机明确。
- **证据强度**：实验覆盖仿真 OOD、跨任务迁移与真实世界分布偏移，并配套逐任务结果、多组消融、探针分析与置信区间，证据链较完整；叠加在预训练 π₀.₅ 上稳定提升的事实，进一步增强了结论的可信度与方法的通用性。
- **主要扣分点**：语言条件化的缺失限制了指令敏感场景的表现；对 V-JEPA 表征的依赖削弱了方法的即插即用性；训练成本信息披露不足；真实评估规模偏小。
- **学术贡献**：论文展示了“与动作生成共享同一主干的潜在转移预测”是一条兼顾性能与效率的可行路径，对未来世界模型与 VLA 结合的研究具有较强的启发与参照价值。综合来看，这是一项立意清晰、实验扎实、改进方向明确的高质量工作。
