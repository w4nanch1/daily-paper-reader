## 摘要
世界模型只有在能改变智能体行为时才对物理AI有用，并且只有在它出错时拒绝这样做才是安全的。我们通过CausalNav研究这一需求的两个方面。CausalNav是一个围绕已识别状态坐标上的有符号、动作条件转移图构建的控制器。在部署时，CausalNav模拟一个小型的干预序列库，将其目标误差转换为策略logit建议，并且仅当无标度预测可靠性证书、策略边际门和argmax一致性门全部通过时才采纳该建议；否则它会完全回退到其自身的基于模型的基础控制器。我们在CartPole-v1和离散化Pendulum-v1上，使用共享的PPO训练器、相同的交互预算和十个保留种子（共200次运行），针对九个受控基线（transformer、递归、分裂潜变量、图、因果归纳和三个最近的基于模型的推理模块）进行了评估，并加入物理参数偏移。CausalNav取得了最佳平均排名（十个中排名1.25）。诊断结果比排名更具信息量：学习到的图在远高于随机水平的程度上恢复了结构（CartPole F1 = 0.59 ± 0.09），但每个种子的结构保真度与每个种子的控制收益无关（r = -0.15, p = 0.67），并且证书在10/10的Pendulum种子上弃权，而在这些种子上强制使用规划器会在回报上付出代价。在我们的设置中，模型保真度并未预测下游控制效用；使世界模型得以安全部署的是经过认证的弃权，而非更优的预测。

## Abstract
A world model is only useful for physical AI if it changes what the agent does, and only safe if it declines to do so when it is wrong. We study both halves of that requirement with CausalNav, a controller built around a signed, action-conditioned transition graph over identified state coordinates. At deployment CausalNav simulates a small library of intervention sequences, converts their objective error into policy-logit advice, and admits that advice only when a scale-free predictive-reliability certificate, a policy-margin gate, and an argmax-agreement gate all pass; otherwise it falls back exactly to its own model-based base controller. We evaluate against nine controlled baselines (transformer, recurrent, split-latent, graph, causal-induction, and three recent model-based reasoning modules) on CartPole-v1 and discretized Pendulum-v1 with physical-parameter shifts, under one shared PPO trainer, one interaction budget, and ten held-out seeds (200 runs). CausalNav attains the best average rank (1.25 of ten). The diagnostic result is more informative than the ranking: the learned graph recovers structure well above chance (CartPole F1 = 0.59 +/- 0.09), yet per-seed structural fidelity is uncorrelated with per-seed control benefit (r = -0.15, p = 0.67), and the certificate abstains on 10/10 Pendulum seeds, where forcing the planner on costs return. Model fidelity did not predict downstream control utility in our setting; certified abstention, not better prediction, is what made the world model safe to deploy.

### 研究动机
- **物理AI智能体的根本困境**：当部署环境的物理机制与训练数据分布不一致时（即物理参数偏移），智能体可能失效。世界模型是标准解决思路——通过模拟候选动作的后果来指导决策。

  1. 模型足够精确，其模拟（rollout）具有参考价值；
  2. 控制器能**判断**模型何时不满足该条件——因为迭代学习模型会累积误差，用不可靠的模型覆盖原本胜任的策略会使系统更糟。

### 整体含义
本文的核心观点是：**模型保真度（fidelity）不能预测控制效用（utility）**，安全部署世界模型的关键不是更好的预测精度，而是经过**认证的弃权机制（certified abstention）**——即在模型不可靠时明确拒绝提供建议。这篇论文通过严格的对照实验证明了这一点，并给出了一个具体的工程实现方案。

## 2. 论文提出的方法论

### 核心思想
CausalNav 构建在"识别后的状态坐标"（identified state coordinates）之上，学习一个**有符号的动作条件转换图**（signed action-conditioned transition graph），在部署时对该图进行干预序列模拟，将模拟结果转化为策略建议，并通过**三重门控**（三个条件全部通过才采纳建议）保障安全。

### 关键构成

#### （1）动作复杂度路由器（Action-complexity router）
- 根据动作集大小选择控制器：
  - **|A| ≤ 2**（如CartPole）：使用三个独立初始化的乐观专家（optimistic expert）集成，其更新规则为：
    ```
    R_opt(z) = z + mean_k f_k(z) + softplus(β) · std_k f_k(z)
    ```
  - **|A| > 2**（如Pendulum）：转换证书直接弃权（abstain），CausalNav完全退化为基础控制器（normalized gated latent residual）。

#### （2）动作条件转换图（Action-conditioned transition graph, §4.2）
- 预测第 i 个坐标的转移方程包含：
  - 自持久项（self-persistence）：$d_i x_{t,i}$
  - 一阶成对系数（pairwise coefficients）：$A_{ij} x_{t,j}$
  - 二阶交互系数（second-order coefficients）：$B_{i,jk} x_{t,j} x_{t,k}$
  - 动作效应（action effects）：$U_{a_t,i}$
  - 偏置项：$b_i$
- 训练损失为一步预测MSE + 稀疏正则（L1，λs=0.05）。
- **不施加同时间片无环约束**——因为该图连接 t 到 t+1 时刻，允许循环依赖，不适用NOTEARS类的无环约束。

#### （3）干预库规划（Intervention-library planning, §4.3）
- 对每个可能的**首动作**，评估三种时间模式（H=8步）：
  - 恒定模式（repeat a）：重复同一动作
  - 脉冲模式（impulse）：先执行 a 一次，然后中性动作
  - 半程模式（half-horizon）：a 执行四步，然后中性动作
- 评分函数为累积分步目标误差：
  ```
  E(a) = (1/H) Σ_h Σ_i w̄_i (x̂_{t+h,i} - τ_i)²
  ```
- 最低成本的模式为标准，生成归一化规划器logit p_t(a)。

#### （4）三重部署门控（Three deployment gates, §4.4）——核心贡献
1. **预测可靠性证书（Predictive-reliability certificate）**：基于无标度一步误差（NRMSE），在48次转移更新后冻结：
   ```
   ρ = clip( (δ - |A|/2 · ē₄₈) / (δ/2), 0, 1 )
   ```
   其中 δ=0.70。该值从预测误差本身计算，**不使用任何回报或偏移标签**。
2. **策略边际门（Policy-margin gate）**：当策略本身很自信时（两个最大logit之差 m_t 较大）抑制建议，通过 exp(-2m_t) 因子实现。
3. **Argmax一致性门（Argmax-agreement gate）**：仅当规划器建议的动作与策略当前贪心动作一致时才允许注入。

最终logits更新公式：
```
ℓ'_t(a) = ℓ_t(a) + g_t · ρ · tanh(α) · exp(-2m_t) · p_t(a)
```

#### （5）精确回退保证（Exact fallback）
Proposition（命题）：当 ρ=0 或 g_t=0 时，建议项消失，ℓ' = ℓ；否则 g_t=1 意味着 p_t 在其最大值处与策略的贪心动作一致——因此**组合后的输出不会改变基础控制器的贪心动作**。这提供了确定性的非回归保证。

### 训练流程
- 使用PPO训练，总损失 = L_PPO + 0.5·L_value - 0.01·H(π) + 0.1·(L_id + L_trans + λ_r·L_repr)
- 策略参数和转换模型参数使用不同学习率（3e-4 vs 1e-2），梯度分别裁剪，**规划器梯度不能影响PPO**。
- 规划器在PPO数据收集和优化期间禁用，避免训练-测试反馈回路。

## 6. 论文的主要结论与发现

### 主结论
1. **CausalNav在排名上表现优异**：平均排名1.25（十个方法中最佳），在CartPole shift、Pendulum ID、Pendulum shift三个单元排名第一，在CartPole ID排名第二；优于第二名SOMBRL（2.25）和第三名GNN-RAG（4.75）。

2. **核心负面发现（本文最有价值的洞见）**：
   - 转换图能有效恢复真实结构（F1=0.59±0.09，明显高于随机水平），一步NRMSE=0.56——按常规标准是"可部署的世界模型"。
   - 但**结构保真度与控制收益无相关**（r=-0.15, p=0.67，分布内；r=-0.18, p=0.62偏移下）。
   - **一步NRMSE与收益竟然正相关**（r=+0.71, p=0.02）——预测最差的种子获得最大收益，虽然作者指出这是混淆效应而非因果。
   - 结论：**两个标准世界模型质量指标完全无法预测实际控制效用，其中一项还指向了错误方向。**

3. **弃权机制的价值验证**：
   - CartPole上7/10种子通过证书（均值ρ=0.32，范围[0,1]）；Pendulum上10/10种子弃权。
   - Pendulum的弃权是正确的：开发期强制规划导致回报损失34–54（ID和shift下均如此）。
   - 证书仅从预测误差出发，不使用回报或偏移标签，即能在部署前识别"模型不可靠"的场景。

4. **精确回退验证**：Pendulum上所有配对差异恒等于0，实证确认了回退属性的精确性。

### 对比消融的价值
- CartPole上CausalNav与其路由专家SOMBRL的差异不显著（ID差-12.17，shift差+11.95，95%CI横跨0）——排名优势主要是三成员集成带来的，而非因果规划本身。论文明确承认了这一点。

- **严格的对照控制**：共享训练器、共享预算、共享监督、仅改变推理模块——这是对"模型保真度是否预测效用"这一问题的最干净检验。
- **诊断与排名并重**：论文明确"诊断结果比排名更具信息量"，主动淡化性能数字、突出科学发现。
- **诚实的负面结果报告**：明确承认"规划器没有起作用"，将核心价值落在方法论洞见上——这在以正面结果为导向的发表环境中难能可贵。

### 工程可复现性
- 提供了完整的产物映射（附录G），包含全部200次运行的逐片段回报、配对统计脚本、绘图代码、组件种子流确定性重初始化方案。

## 8. 不足与局限

### 实验覆盖局限
- **基准过于简单**：两个低维经典控制任务（CartPole和Pendulum），结论能否推广到复杂物理系统（机器人、自动驾驶）存在根本性疑问。
- **训练预算极低**：4096次交互远未收敛，论文自认"returns are not converged and the intervals are wide"。
- **统计功效有限**：仅10个种子，且CartPole回报呈双峰分布，配对差异的置信区间很宽——关键结论（"无差异"）可能有II型错误风险（即可能掩盖真实存在的效应）。

### 方法局限
- **监督式状态识别**：识别坐标由辅助监督信号直接给出（L_id），因此实验**不涉及无监督因果表示学习**，结论适用范围被显著收窄。
- **参数不匹配**：CartPole分支使用三成员集成的模型容量大于单成员参考方法，排名优势部分来自容量而非方法本身——论文公开承认"参数匹配对照是下一个自然实验"。
- **干预库过于简单**：仅三种时间模式×首动作的组合，对于需要能量积累和相位敏感力矩序列的Pendulum来说明显不足——这也是Pendulum全部弃权的直接原因之一。
- **路由器选择偏差**：动作数阈值（|A|≤2 vs |A|>2）是在观察仅两个数据集后选定的，可能编码了基准特定选择而非普适规律。

### 理论局限
- **精确回退不等同于安全保证**：论文明确声明Proposition只是"确定性的动作选择非回归属性"，而非概率性控制安全保证；物理/安全关键部署仍需校准的不确定性估计、保守后备控制器和领域特定验证。

### 应用限制
- Pendulum使用五档离散化力矩，结论针对该离散版本而非连续控制接口。
- 物理偏移仅改变物理参数，不改变观测语义、拓扑结构或奖励——实战中更复杂的分布偏移类型未被覆盖。

### 未来工作建议
- 参数匹配对照实验
- 预注册的基准套件（以消除基准选择压力）
- 更丰富的干预规划库、更高维环境验证
