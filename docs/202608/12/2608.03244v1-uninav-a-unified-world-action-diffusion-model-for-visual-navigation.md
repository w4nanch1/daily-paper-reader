## 摘要
图像目标视觉导航是具身智能体的基本能力。现有的导航策略能高效预测航点轨迹，但缺乏视觉预见性；而导航世界模型虽能预判未来观测，却往往需要代价高昂的规划展开。我们提出UniNav，一种统一的世界-动作模型，通过单一扩散过程生成未来视觉观测和连续航点轨迹。给定历史帧和目标图像，UniNav在单个Transformer内联合去噪视觉和航点标记，在共享框架中统一未来预测与动作生成。为改善空间 grounding，我们引入几何感知的相机标记。我们还同时使用带轨迹标注的导航数据和纯视频数据进行训练，使模型能从无航点标注的多样化视频中受益。基于该统一框架，我们提出两个变体：UniNav-Full联合预测可解释的未来观测及其对应轨迹，而UniNav-Fast在推理时移除未来图像标记以实现高效轨迹预测。导航基准实验表明，UniNav在所有数据集上的ATE均优于最强基线。通过一步推理，UniNav-Fast的延迟达0.1秒，且无显著精度下降。代码将开源。

## Abstract
Image-goal visual navigation is a fundamental capability for embodied agents. Existing navigation policies efficiently predict waypoint trajectories but lack visual foresight, while navigation world models can anticipate future observations but often require costly planning rollouts. We present UniNav, a unified world-action model that generates future visual observations and continuous waypoint trajectories through a single diffusion process. Given history frames and a goal image, UniNav jointly denoises visual and waypoint tokens within a single transformer, unifying future prediction and action generation in a shared framework. To improve spatial grounding, we incorporate geometry-aware camera tokens. We also train on both trajectory-labeled navigation data and video-only data, enabling the model to benefit from diverse videos without waypoint annotations. Based on this unified framework, we introduce two variants: UniNav-Full jointly predicts interpretable future observations and their corresponding trajectories, while UniNav-Fast removes future-image tokens at inference for efficient trajectory prediction. Experiments on navigation benchmarks show that UniNav outperforms the strongest baseline in ATE across all datasets. With one-step inference, UniNav-Fast achieves a latency of 0.1s without a substantial accuracy drop. Code will be released.

## 1. 核心问题与整体含义（研究动机与背景）

- 视觉导航（image-goal visual navigation）要求智能体根据第一视角观测到达目标图像所在位置，并需在不同环境与机器人平台上泛化。
- 现有方法存在两类割裂：
  - **纯策略（action-only）模型**（如 GNM、ViNT、NoMaD、FlowNav）：能高效预测航点轨迹，但缺乏对“未来视觉状态”的显式建模，可解释性差，难以进行基于视觉预判的推理。
  - **导航世界模型（navigation world models）**（如 NWM、CompACT、RAE-NWM）：可生成未来观测，但采用“先生成、再评估”的规划范式，每个候选轨迹都要独立 rollout，计算开销大，不满足实时闭环导航需求。
- 因此，UniNav 的核心诉求是 **在单一扩散生成过程中同时统一“未来视觉预测”与“动作（航点）生成”**，既提供可解释的视觉预见，又保持高效实时的航点推理能力。

## 2. 方法论：核心思想、关键技术与流程

### 2.1 核心思想

- 借鉴机器人操作领域的统一世界-动作模型（World-Action Model），将未来帧视频潜变量、航点轨迹、相机几何 token 全部视为可去噪的 token 序列，由同一个 Transformer 在 flow-matching 框架下联合去噪。
- 初始化自预训练视频扩散模型 Wan2.1-1.3B，以获得强大的视频先验。

### 2.2 关键模块

- **视觉 token**：历史帧、目标帧、未来帧经过冻结的视频 VAE 编码并 patchify 为时空潜 token。
- **航点 token**：连续 K 步局部航点 `a_{t+1:t+K} ∈ R^{K×3}`（相对平移与偏航角），加噪后由 MLP 映射到隐空间。
- **相机 token（Geometry-Aware Camera Tokens）**：使用冻结的几何基础模型（Depth Anything 3 / DA3）从历史与未来视图提取相机 token，提供 3D 结构监督；训练时将其作为额外去噪目标。
- **统一 token 序列**：`[h_cam | h_pred | h_traj | h_hist | h_goal | h_reg]`，其中 register token 用于全局信息交换；视觉 token 保持预训练位置编码，非视觉 token 使用 identity 位置编码。
- **异步注意力（Asymmetric Attention）用于 UniNav-Fast**：训练时防止非未来 token 去 attend 到带噪未来图像 token，使航点预测不依赖未来图像表示；推理时可完全丢弃未来图像 token。

### 2.3 训练目标

- 统一 flow-matching 目标，对三种模态分别定义加噪与速度场：
  - `z_m = (1 - σ_m) x_m + σ_m ε_m`，`u_m = ε_m - x_m`
  - **视频损失** `L_vid`：均方误差，预测未来视频潜变量的速度场
  - **轨迹损失** `L_traj`：对每个航点维度使用 SmoothL1 损失
  - **相机损失** `L_cam`：均方误差，监督相机 token 的速度场
- 总损失：`L = λ_vid m_vid L_vid + λ_traj m_traj L_traj + λ_cam m_cam L_cam`
  - 轨迹标注数据启用全部损失；纯视频数据仅启用视频与相机损失（`m_traj=0`），从而可以利用无标注视频。

### 2.4 推理流程

- **UniNav-Full**：从随机噪声初始化未来图像 token 与航点 token，逐步去噪，联合输出可执行航点轨迹与对应的未来观测。
- **UniNav-Fast**：推理时移除未来图像 token，直接仅对航点（和相机）token 采样，避免未来帧去噪与 VAE 解码，显著降低延迟。

## 6. 主要结论与发现

- UniNav 在 **所有四个数据集上 ATE 均优于最强基线**：RECON 降低 3.7%，SaCSoN 降低 24.7%，GO Stanford 降低 18.2%，SCAND 降低 6.8%；RPE 也普遍更优。

## 7. 优点

- **统一框架**：将未来观测与动作生成整合进同一扩散过程，兼顾可解释视觉预见与实时动作输出。
- **几何感知**：引入冻结几何模型导出的相机 token，弥补纯外观匹配在空间 grounding 上的不足，且推理时不需未来观测。
- **数据可扩展性**：借助视频-only 数据训练，降低对昂贵航点标注的依赖，同时不引入伪轨迹噪声。
- **效率设计**：UniNav-Fast 通过异步注意力解耦未来图像与航点预测，在精度几乎不降的前提下把延迟压到 0.1s 量级，相比 NWM 的约 900 秒/数千 NFE 优势巨大。
- **继承视频先验**：基于预训练 1.3B 视频扩散模型，小规模数据上即可获得较强的泛化与生成质量。
