## 摘要
现有的自动驾驶世界模型通常执行未来视频、占用状态、BEV表示或智能体运动的密集预测。我们认为，规划并不需要重建完整的未来世界，而只需关注影响未来自车动作的场景特征。基于这一观点，我们提出了Auto-JEPA，一种面向动作的潜在世界模型，通过联合嵌入预测学习连续的未来驾驶意图。给定视觉观察、自车运动历史和导航命令，Auto-JEPA预测一个与未来自车轨迹的潜在表示对齐的意图嵌入。预测的意图从固定的轨迹存储器中检索可执行的轨迹，然后由场景条件候选选择模块进行排序。Auto-JEPA保持视觉编码器冻结，不要求显式的感知标注，也不使用学习到的轨迹生成器。通过仅优化轨迹表示、意图预测和候选选择这些任务特定模块，Auto-JEPA在NAVSIM v1上达到91.3 PDMS，在NAVSIM v2上达到89.1 EPDMS。语义遮挡实验表明，遮挡动态智能体区域导致的平均意图变化是等面积随机遮挡的2.97倍。此外，遮挡影响未来驾驶的车辆会显著改变预测意图和所选轨迹，而遮挡不影响驾驶的车辆时两者基本保持不变。这些结果表明，未来意图预测鼓励模型关注与规划相关的视觉特征，并支持无需密集未来世界建模的高质量规划。

## Abstract
Existing autonomous-driving world models typically perform dense prediction of future videos, occupancy states, BEV representations, or agent motion. We argue that planning need not reconstruct the complete future world, but only focus on scene features that affect future ego action. Based on this perspective, we propose Auto-JEPA, an action-oriented latent world model that learns continuous future driving intent through joint-embedding prediction. Given visual observations, egomotion history, and navigation commands, Auto-JEPA predicts an intent embedding aligned with the latent representation of the future ego trajectory. The predicted intent retrieves executable trajectories from a fixed trajectory memory, which are then ranked by a scene-conditioned candidate selection module. Auto-JEPA keeps the visual encoder frozen, requires no explicit perception annotations, and uses no learned trajectory generator. By optimizing only task-specific modules for trajectory representation, intent prediction, and candidate selection, Auto-JEPA achieves 91.3 PDMS on NAVSIM v1 and 89.1 EPDMS on NAVSIM v2. Semantic occlusion experiments show that masking dynamic-agent regions induces an average intent change 2.97x that of equal-area random masking. Moreover, occluding vehicles that affect future driving substantially changes the predicted intent and selected trajectory, whereas both remain essentially unchanged when non-influential vehicles are occluded. These results show that future-intent prediction encourages the model to focus on planning-relevant visual features and supports high-quality planning without dense future-world modeling.

**研究动机：** 现有自动驾驶世界模型（如生成式视频预测、占用网格预测、BEV表示预测、多智能体轨迹预测等）通常需要对未来场景进行**密集预测**，即重建未来视频帧、占据状态或完整场景演进。论文指出，这种"重建整个未来世界"的目标存在两个问题：

- **计算浪费**：模型中很大一部分容量被分配到与自车当下决策无关的场景元素（如路边静止物体、不影响自车行驶的远处车辆等）上。
- **错误传播**：对周围场景的感知和预测误差会进一步传播到下游规划模块，影响规划质量。

**核心论点：** 规划并不需要重建完整的未来世界，**只需要关注那些会影响未来自车动作的场景特征**。基于此观点，论文提出了一种"面向动作"（action-oriented）的潜在世界模型——Auto-JEPA，通过预测**连续的未来驾驶意图**（future driving intent）来驱动规划，避免密集未来重建。

**整体含义：** Auto-JEPA 以端到端方式从传感器观测直接输出可执行轨迹，不依赖显式感知标注、不学习轨迹生成器，却能在 NAVSIM 基准上取得领先性能。这表明"意图级预测"可以替代"场景级重建"成为规划核心，为自动驾驶世界模型提供了一种新的范式选择。

## 2. 方法论

### 2.1 核心思想

Auto-JEPA 的核心思想是：**预测未来自车轨迹的潜表征（而非场景的像素或结构表征）**。该潜表征被称为"连续驾驶意图"，它既作为训练时的预测目标，也作为推理时的检索键（retrieval key），直接参与轨迹规划。

### 2.2 整体框架

系统分为四个阶段/components：

1. **轨迹潜空间预训练（Stage 1）**：训练一个轨迹自编码器，将未来的 8 个二维路点（4秒时域，0.5秒间隔）编码为 8×1024 的潜表征。
2. **视觉意图预测（Stage 2）**：用冻结的 V-JEPA 2 视觉编码器提取四帧前视图像的视觉 token，配合历史自车位置编码和导航命令编码，由 24 层 Transformer JEPA Predictor 预测未来的意图潜表征。
3. **非参数轨迹检索**：从包含 110,335 条真实轨迹的记忆库中，通过扁平余弦相似度检索 Top-300 候选轨迹。
4. **场景评分与可行性门控**：场景条件评分器（初始化自 CLOVER）对候选轨迹进行质量排序；独立的可行驶区域门控（DAC gate）过滤可能违规的轨迹。

### 2.3 关键技术细节

**（1）轨迹意图表征**（公式 1–3）：
- 未来轨迹表示为 Y = [(x₁,y₁), ..., (x₈,y₈)] ∈ R⁸ˣ²
- 轨迹编码器 E_traj 将 Y 映射为 Z⁺ ∈ R⁸ˣ¹⁰²⁴，解码器重构轨迹
- 损失函数：L_traj = L_xy + λ_e·L_end + λ_v·L_vel + λ_a·L_acc（坐标、终点、速度、加速度四个监督项）
- 预训练后解码器丢弃，轨迹编码器冻结，作为目标和记忆的共享编码空间

**（2）联合嵌入预测目标**（公式 8–12）：
预测意图 Ẑ 与目标意图 Z⁺ 的损失包含三个部分：

- **特征对齐损失**：L_feat = SmoothL1(Norm(Ẑ), Norm(Z⁺))（权重 0.1）
- **Token-wise 余弦对齐**：L_cos = 平均 8 个时间 token 的余弦距离（权重 2.0）
- **批量级 InfoNCE 对比损失**：将完整意图序列展平归一化，同场景目标为正样本，其他场景目标为负样本，温度 τ = 0.07

总损失 L_intent = 0.1·L_feat + 2.0·L_cos + L_NCE。

**（3）推理流程**：
- 预测意图 Ẑ 展平 L2 归一化后 q = Norm(vec(Ẑ))
- 与记忆库中每条轨迹的潜表征 m_n = Norm(vec(Z_n)) 做余弦相似度 r_n = qᵀm_n
- 取 Top-K（K=300）候选 → 场景评分器打分 → DAC 门控过滤（阈值 0.2）→ masked argmax 选择最终轨迹
- 若全部被门控拒绝，则回退到未过滤的评分排序

**（4）设计特点**：

- 视觉编码器和轨迹编码器全程冻结，仅训练预测器、历史编码器、命令编码器、评分器和门控
- 无需目标框、占用、语义地图、周围智能体运动等标注
- 无学习型轨迹生成器，完全依赖记忆检索

## 6. 主要结论与发现

1. **性能表现**：在仅使用单目前视相机、无感知标注的条件下，Auto-JEPA 在 NAVSIM v1 获得 **91.3 PDMS**，在 NAVSIM v2（更新官方评估）获得 **89.1 EPDMS**，达到或超过多种使用 LiDAR 或多相机的方法。
2. **意图检索有效**：将意图预测替换为固定码本时 PDMS 从 91.3 骤降至 52.6，说明场景条件化的意图检索是关键因素。
3. **评分器和门控各有贡献**：评分器贡献约 3.7 PDMS；门控贡献约 0.3 PDMS，并将 DAC 从 97.9 提升到 98.3。
4. **选择性关注规划相关信息**：遮挡动态智能体区域使意图变化是等面积随机遮挡的 **2.97 倍**，且 71.1% 的场景中动态智能体遮挡影响更大；遮挡影响驾驶的车辆会显著改变输出，遮挡无关车辆则几乎不变——表明模型学会了**任务驱动的场景注意力分配**，且这些行为是在没有任何物体级监督的情况下涌现的。
5. **无密集未来重建也能实现高质量规划**：预测未来自车轨迹的潜表征足以支撑规划，挑战了"世界模型必须重建完整场景"的传统认知。

## 7. 优点

1. **概念创新**：将"世界模型"重新定义为"面向动作的未来意图预测器"，避免密集重建的成本和噪声传播，思想简洁而有力。
2. **系统设计优雅**：预测目标（未来轨迹潜表征）、监督目标（冻结轨迹编码器）和推理目标（非参数记忆检索）共享同一潜空间，形成自洽闭环，无须额外生成器。
3. **轻量且高效**：视觉编码器冻结、零感知标注、无参轨迹生成，仅训练少量任务模块，训练和推理开销远小于生成式世界模型。
4. **可解释性**：语义遮挡实验提供了较强的可解释性证据，表明模型隐式学会了关注"谁对自车决策重要"，这对自动驾驶安全认证有积极意义。
5. **实验对比全面**：在 v1 和 v2 两个协议下与 12+ 种方法对比，覆盖多种传感器配置和类型的方案。

## 8. 不足与局限

1. **记忆覆盖局限**：检索式规划的上界受限于固定轨迹记忆库的覆盖范围。若可行机动不在候选池中，评分器和门控无法"创造"新轨迹。作者也承认 K=200→300 的收益递减，说明单纯扩大池子并非可持续路径。
2. **缺乏生成能力**：模型无法提供场景级未来预测（如周围智能体行为演化），因此不适用于交互式仿真、反事实场景生成等应用。
3. **评估与统计局限**：benchmark 结果来自单次确定性评估，未报告均值/方差；缺少多 seed 的鲁棒性验证。NAVSIM 本身是非反应式基准，无法完全反映闭环真实路测中的表现。
4. **评分器校准风险**：最终性能依赖评分器和门控的校准质量，分布偏移时可能误伤合法轨迹或漏检违规轨迹。全过滤回退机制只能保证输出非空，无法修复排名错误。
5. **计算资源报告不完整**：未给出具体的训练时长和能耗，限制了可复现性评估。
6. **传感器输入有限**：仅使用前视相机，未集成环视相机或 LiDAR，在遮挡严重的复杂路口场景中的表现有待验证。
