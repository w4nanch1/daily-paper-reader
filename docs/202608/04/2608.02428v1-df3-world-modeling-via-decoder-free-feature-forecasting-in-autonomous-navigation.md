## 摘要
从视频序列预测未来状态是自主机器人系统面临的关键挑战，也是世界建模的基本目标。先前在像素层面操作的生成方法不可避免地过度强调与任务无关的细节，导致计算开销过大。虽然基于潜变量的方法试图通过直接预测特征来缓解这一问题，但状态到任务映射对重型解码器的持续依赖仍然是计算瓶颈。在这项工作中，我们提出了无解码器特征预测（DF$^3$），这是一种新颖的框架，完全在潜空间内建模世界演化并直接推导任务输出，彻底消除了对解码器的需求。具体来说，DF$^3$ 将可学习的空间查询注入冻结的视觉基础模型的终端块，直接提取未来状态表示。通过采用轻量级、统一的运动感知上下文融合（MACF）机制，无缝集成粗粒度光流扭曲与细粒度潜变量互相关，这些查询与历史令牌表示交互，以显式对齐和预测下一帧的特征。随后，一组专门的任务查询探测这些预测特征以完成下游任务。在公开基准测试和机器人模拟器中的零样本部署上的大量实验表明，DF$^3$ 在实现与最先进方法相当的性能的同时，为集成感知和控制提供了卓越的效率和灵活性。

## Abstract
Forecasting future states from video sequences is a critical challenge for autonomous robotic systems and a fundamental objective of world modeling. Prior generative methods operating at the pixel level inevitably overemphasize task-irrelevant details, leading to prohibitive computational overhead. While latent-based approaches attempt to mitigate this by predicting features directly, the persistent reliance on heavy decoders for state-to-task mapping remains a computational bottleneck. In this work, we propose Decoder-Free Feature Forecasting (DF$^3$), a novel framework that models world evolution entirely within the latent space and directly derives task outputs, completely eliminating the need for a decoder. Specifically, DF$^3$ injects learnable spatial queries into the terminal blocks of a frozen vision foundation model to extract future state representations directly. By employing a lightweight, unified Motion-Aware Context Fusion (MACF) mechanism that seamlessly integrates coarse flow warping with fine-grained latent cross-correlation, these queries interact with historical token representations to explicitly align and forecast the feature of the next frame. Subsequently, a specialized set of task queries probes these forecasted features for the downstream task. Extensive experiments on public benchmarks and zero-shot deployment in a robotic simulator demonstrate that DF$^3$ achieves performance comparable to state-of-the-art methods while offering superior efficiency and flexibility for integrated perception and control.

## 1. 核心问题与研究动机

- **问题背景**：未来状态预测是自主导航与世界建模的核心能力。现有方法可分为两类：
  - **像素级生成方法**：直接在原始像素空间预测未来帧，计算开销极大，且会过度建模纹理、光照等与任务无关的高频细节；下游任务还需额外的感知/解码阶段将像素转译为语义输出。
  - **潜变量（latent）方法**：在语义特征空间预测未来状态，避免了像素噪声，但仍依赖**重型解码器**（如 Transformer 时空解码器）进行上下文建模，并需另加任务专用解码器将预测特征翻译为任务输出，形成新的计算瓶颈。
- **核心研究问题**：能否完全在视觉基础模型（VFM）的编码器空间内完成特征预测，从而彻底去除解码器？
- **论文答案**：提出 **DF$^3$（Decoder-Free Feature Forecasting）**——完全在冻结的 ViT 潜空间中进行未来状态预测，并直接得到下游任务输出，实现"无解码器"世界建模。

## 2. 方法论

### 2.1 核心思想
- 利用**冻结的 DINO 系列 ViT 编码器** $E$（具体为 DINOv3-ViT-B/16），不微调其权重。
- 将**可学习预测查询（prediction queries）** 注入 ViT 终端块，与历史上下文特征交互，直接输出下一帧的特征表示。
- 将**可学习任务查询（task queries）** 注入同一终端块，探测预测特征以直接产生任务输出（如语义分割），全程无需解码器。

### 2.2 关键流程（Pipeline）
1. 历史帧 $\{I_1,\dots,I_T\}$ 分别经过编码器早期层 $L_1$，得到上下文特征 $F_{L_1}(I_t) = \{f^{pref}_{L_1}(I_t), f^{patch}_{L_1}(I_t)\}$（含前缀 token 与 patch token）。
2. 预测查询 $Q_{pred} \in \mathbb{R}^{(H'W' + N_{pref}) \times C}$ 与历史特征拼接后输入终端块 $L_2$ 进行自注意力交互。
3. 输出经**运动感知上下文融合（MACF）** 模块细化，得到预测特征 $\hat{F}_{L_1}(I_{T+1})$。
4. 任务查询 $Q_{task}$ 与预测特征拼接再次注入 $L_2$，输出经轻量 MLP 头生成任务结果。

### 2.3 结构化查询注意力（Structured Query Attention）
- 采用**非对称注意力掩码**：上下文 token 之间可自由互相关注，但**禁止**上下文 token 关注预测查询；预测查询可关注所有 token。
- 该因果设计防止信息泄漏，保证上下文表示不被查询污染。

### 2.4 运动感知上下文融合（MACF）
由两个并行分支加动态融合组成：
- **光流扭曲分支（Flow-based Warp Branch）**：
  - 由查询预测稠密潜空间光流场 $\Delta p = \text{MLP}_{flow}(q_{patch})$；
  - 用其扭曲最近历史特征图，计算与当前查询的差值作为粗粒度更新方向 $M_{warp}$。
- **潜空间互相关分支（Latent Cross-Correlation Branch）**：
  - 在 $f_{L_1}^{patch}(I_{T-1})$ 与 $f_{L_1}^{patch}(I_T)$ 之间做局部窗口软匹配（cosine 相似度 + 温度 softmax），得到历史语义运动 $V_{hist}$，再投影为细粒度运动注入 $M_{xcorr}$。
- **动态融合**：
  - 以学习到的 sigmoid 门控 $G(q_{patch})$ 调节融合残差：$\hat{f}^{patch}_{L_1}(I_{T+1}) = q_{patch} + G(q_{patch}) \odot \text{MLP}_{fuse}([M_{warp}, M_{xcorr}])$。
  - 对全局前缀 token 使用轻量时间外推器，基于历史差分预测其演化。

### 2.5 训练目标
- 纯特征级监督，无需与下游解码器联合训练：
  - $L_{sim} = E_t\left[1 - \cos(\hat{F}_{L_1}(I_{t+1}), F_{L_1}(I_{t+1})) + \lambda_{huber} \cdot \text{Huber}(\hat{F}_{L_1}(I_{t+1}), F_{L_1}(I_{t+1}))\right]$。
  - 同时作用于 patch token 与前缀 token，兼顾方向对齐与幅值稳定。

## 3. 实验设计

- **下游评估指标**：从预测特征经 EoMT 式任务查询得到语义分割结果，报告 **mIoU** 与 **MO-mIoU**（动态类别如车、骑行者、行人的 mIoU）。

### 3.2 对比方法

## 6. 主要结论与发现

- DF$^3$ 在 Cityscapes 短期预测达到 **69.9 mIoU / 68.7 MO-mIoU**，中期达 **58.2 / 56.5**，与 DINO-Foresight（71.8/71.7，59.8/57.6）接近，小幅落后但差距有限。
- 效率优势显著：**GFLOPs 减少 36%**（1440.63 vs 2256.07），**延迟降低 70%**（292.4ms vs 971.1ms），**峰值显存降低 67%**（3.1GB vs 9.5GB），**预测参数量减少 41%**（177.0MB vs 302.5MB）。
- 消融验证了 MACF 的有效性：单独使用光流扭曲或互相关均有提升，两者结合（69.9）显著优于简单拼接（59.9）和纯注意力（63.0）；搜索半径 $r=\{1,2,4,8\}$ 最优。
- 零样本跨具身部署（汽车视角 → 四足机器人）证明预测特征包含可迁移的运动语义，足以支撑安全规划。

## 7. 优点

- **创新性**：首次在冻结 VFM 编码器空间内实现"无解码器"未来预测，直接跳过像素生成和特征/任务双重解码的瓶颈。
- **高效简洁**：查询注入 + 轻量 MACF 替代重型时空解码器，架构极轻，适合实时部署场景（延迟/显存大幅下降）。
- **灵活解耦**：预测查询与任务查询可独立训练、灵活组合，世界模型与下游任务解耦。
- **模块设计精良**：非对称注意力掩码防止信息泄漏；流动扭曲与互相关分别建模粗粒度位移与细粒度历史运动，互补有效；门控融合自适应调节残差权重。
- **实验视野好**：除标准基准外有模拟器零样本部署，验证了跨域、跨具身泛化能力，贴近实际应用。

## 8. 不足与局限

- **精度略低于 SOTA 基线**：mIoU 比 DINO-Foresight 低约 2 个点，属于以轻微精度换大幅效率的权衡。
- **空间过平滑**：预测特征在冻结 ViT 的下采样特征空间内生成，物体边界粗糙、薄结构锐度下降（作者承认这是固有折衷）。
- **仅支持观测驱动预测**：当前框架不支持动作条件预测（action-conditional），无法模拟干预后果，限制闭环控制与交互式规划（作者列为明确局限）。
- **评估覆盖面偏窄**：量化评估仅限 Cityscapes 单一数据集、单一分割下游任务、单一对比基线，缺少更广泛的多数据集/多任务/多基线验证。
- **应用风险**：零样本部署到四足机器人时轨迹与 Oracle 存在空间错位，且仅定性展示；安全关键场景的可靠性仍需更严格评估。
