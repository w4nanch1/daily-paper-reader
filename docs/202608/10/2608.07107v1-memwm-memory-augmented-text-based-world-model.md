## 摘要
世界模型越来越广泛地用于通过预测环境状态如何响应代理动作来支持代理中的规划。然而，流畅的下一状态预测仍可能遗漏任务关键事实、破坏产品属性或应用不正确的转换规则。为了解决这些系统性预测错误，我们引入了MemWM，一种基于记忆增强的文本世界模型。MemWM利用世界记忆——一个包含转换规则、状态缓存和难预测事实的精选记忆库——来调节下一状态的想象。我们通过结构化状态保真度（Structured State Fidelity, SSF）评估事实状态保持，该指标通过基准特定的事实和字段对预测状态进行评分。与SFT相比，记忆增强训练使SSF提升了高达206.3%。在完整的规划设置中，我们保持策略模型冻结，并提供策略侧世界技能：检索到的任务级技能和用于动作选择的逐步修正指导。在ALFWorld、WebShop和ScienceWorld上，与SFT训练的世界模型代理相比，记忆增强代理提升了下游成功率，相对增益高达65.4%。敏感性分析进一步表明，在不同记忆和动作预算设置下，检索到的记忆提高了任务成功率和效率。

## Abstract
World models are increasingly used to support planning in agents by predicting how environment states evolve in response to agent actions. Yet fluent next-state predictions can still omit task-critical facts, corrupt product attributes, or apply incorrect transition rules. To address such systematic prediction errors, we introduce MemWM, a memory-augmented text-based world model. MemWM uses world memory, a curated memory bank of transition rules, state caches, and hard-to-predict facts, to condition next-state imagination. We evaluate factual state preservation with Structured State Fidelity (SSF), which scores predicted states through benchmark-specific facts and fields. Compared with SFT, memory-augmented training improves SSF by up to 206.3%. In the full planning setting, we keep the policy model frozen and provide policy-side world skill: retrieved task-level skills and step-wise corrective guidance for action selection. Across ALFWorld, WebShop, and ScienceWorld, memory-augmented agents improve downstream success over an SFT-trained world-model agent, with up to a 65.4% relative gain. Sensitivity analyses further show that retrieved memory improves task success and efficiency under different memory and action-budget settings.

## 1. 核心问题与整体含义（研究动机与背景）

- 大型语言模型（LLM）代理被广泛用于交互式环境中的顺序决策（如具身家务、科学仿真、网页导航）。世界模型通过预测“动作 → 状态演化”来支持代理在行动前进行想象和规划。
- **核心痛点**：现有文本世界模型的下一状态预测虽然在字面上流畅自然，却存在**系统性状态保真瓶颈**——遗漏任务关键事实（如物品绑定关系）、破坏产品属性（如价格、选项）、或应用错误的转移规则。例如：移动了房间却忘记物品放在哪个容器里；科学环境中改变了设备状态或数值；购物代理丢失产品 ID。
- **评价指标的误导性**：精确匹配（Exact Match）过于严格——无害的同义改写、格式化变化得零分；词级 F1 过于宽松——互换对象/位置/价格后仍有大量重叠 token 而得分虚高，导致一个不可靠的世界模型可能在表面指标上表现良好。
- **核心研究问题**：如何让文本世界模型利用经验衍生的记忆，避免系统性的事实、规则、状态转移错误，同时保持想象状态对行为关键世界事实的忠实性？

## 2. 论文提出的方法论

- **核心思想**：为世界模型配备**外部化记忆库**，将训练数据/历史经验中提炼出的关键知识作为预测时的条件信息，弥补参数化知识的不确定性。

### 2.1 世界记忆（World Memory）
- 基于过去的世界模型经验构建的**精选记忆库**，包含三类条目：
  - **转移规则**（transition rules）：如动作前置条件、设备操作规则；
  - **状态缓存**（state caches）：可复用的结构化状态记录；
  - **难预测事实**（hard-to-predict facts）：模型易遗漏或易扭曲的实体绑定、数值、标识符等。
- 条目保持精炼并带有轻量级检索键；检索条件来自当前上下文与候选动作。

### 2.2 策略侧世界技能（World Skill）
- 与“世界记忆”分离的**策略侧记忆通道**，在完整代理中用于指导动作选择而非状态预测：
  - **世界任务技能**：在回合开始时检索一次，提供任务级高层策略；
  - **世界修正指导**：在每个决策步骤动态检索，提供局部纠错提示（如避免无效动作循环、检查选项等）。
- 在完整代理中策略模型保持冻结，不进行任何策略微调，性能提升完全来自于记忆引导的想象和检索式动作指导。

### 2.3 结构化状态保真度（SSF）评价指标
- 针对现有表面重叠指标的不足，提出**结构化状态保真度（Structured State Fidelity, SSF）**：
  - 首先通过提取器 \( \Phi_d \) 将预测状态与黄金状态投影为**基准特定的结构化事实**；
  - 然后在各组件 \( c \) 上计算相似度并加权求和：

\[
SSF_d(\hat{s}_{t+1}, s_{t+1}) = \sum_{c \in C_d} w_c \cdot sim_c(\hat{z}_c, z_c)
\]

  - 组件相似度依据类型选择：分类字段用精确匹配、事实/标识符集合用集合 F1、文本字段用词法 F1、数值字段用相对误差。
  - ALFWorld/scienceworld 采用事实集 F1；WebShop 采用页面字段的加权分数（用确定性规则解析页面）。

### 2.4 规划流程（MemWM Planning）
1. 根据任务目标检索任务级技能 \( \tau \)；
2. 在每个决策步，由当前状态/历史检索修正指导 \( \gamma_t \)；
3. 策略模型提出候选动作集 \( A_t \)；
4. 候选动作检索世界记忆并生成记忆条件化下一状态 \( \hat{s}_{t+1} \)；
5. 对每条轨迹打分后选择最高分动作执行，并更新历史与记忆证据。

## 6. 论文的主要结论与发现

- **记忆增强训练一致提升结构化状态保真度**：Mem-Aug RL 在手写的九个模型-基准单元中全部取得最佳 SSF；在 WebShop 上相对 RL 无记忆提升最大（+0.175 / +0.070 / +0.135），ALFWorld 与 ScienceWorld 提升虽小但稳定。与 SFT 相比，SSF 最高提升 206.3%。
- **测试时检索确实提供有效信息**：从预测提示中移除记忆块会一致降低 SSF（图 4），说明记忆不是惰性上下文，而是参与了想象过程。
- **无需策略训练即提升下游表现**：在冻结策略条件下，MemWM 在 ALFWorld 总体和 WebShop total 上优于 SFT 世界模型代理；MemWM+Skill 进一步强化动作选择，获得最佳 ALFWorld 结果。下游成功率相对增益最高达 65.4%。
- **提升不是靠更多搜索或更大记忆预算**：不同候选动作预算下均有收益，成功任务步数相当或更少；完整记忆成功最高，重度记忆 dropout 降低性能。

## 7. 优点与亮点

- **提出了更符合文本世界模型需求的评价指标**：SSF 用领域特定的结构化事实替代表面重叠，能更准确地区分“无害改写”与“行为关键事实损坏”，并给出了详细的提示模板、解析规则与验证（盲注标注者试验）。
- **记忆设计具有清晰的功能分工**：将“状态预测用的世界记忆”与“动作选择用的策略技能”分离，分别服务想象与决策，概念清晰、可插拔性强。
- **策略模型保持冻结**：在完全冻结策略骨干的条件下仅通过世界模型记忆增强带来提升，强调了世界模型在代理中的独立价值，也更接近真实应用场景中的低成本部署需求。
- **实验证据丰富且多维**：从 SSF 到下游任务表现，再到 dropout 敏感性和组件消融，配有跨基准与跨模型的一致性验证，并且包含跨域迁移测试，提高了结论的稳健性。

## 8. 不足与局限

- **算力信息不透明**：未报告具体 GPU 型号、总训练时长或浮点预算，增加了复现难度（尤其对于 GRPO 训练三个不同规模的模型）。
- **指标提取器存在潜在偏差风险**：ALFWorld 依赖小型 LLM 提取器（身份一致性仅 97.1%），ScienceWorld 的混合提取器在规整化规则上较复杂，WebShop 保留确定性解析器，但 ID 对齐假设等设计可能导致对特定页面的偏置；提取器本身仍可能掩盖或夸大部分错误。
- **记忆构建成本较高**：每条记忆需要基于训练轨迹/预测失败的半自动化挖掘与人工规则编写，迁移到新环境时需重新定义事实模式与缓存结构；论文虽测试了 CookingWorld 的跨域可复制性，但没有量化构建新记忆库所需的人工工作量。
- **提示基线的对比公平性存疑**：表 2 中的 CoT/ReAct/RAP/ITP 采用先前研究的已报告结果，可能与本文代理接口实现存在细节差异，非严格同实验条件下的平行比较；此外表 2 中 ScienceWorld 的拆分处理并不完全一致（有无 seen/unseen 分开）。
- **策略侧技能高度依赖启发式触发条件**：修正指导依赖人工编写的触发规则，对不常见失败模式覆盖有限；且技能注入会显著增加每次决策的上下文长度，可能影响推理开销。
- **应用范围仅限于文本界面**：SSF 与记忆机制的验证均未涵盖视觉或更复杂的多模态环境，其向具身/多模态世界模型的推广性尚未得到检验。
