## 摘要
世界-动作建模已成为机器人控制的一种有前景的范式，因为它使模型能够超越对观察的被动反应，预测场景将如何演变。然而，现有的WAM通常会产生大量的计算开销。像素空间方法通常将大量容量分配给与控制不直接相关的视觉细节，而一些潜在空间方法则需要多阶段训练来构建推理空间。由此产生的训练成本使得这些方法在有限的计算预算下难以训练。在这项工作中，我们提出了LiLa-WAM，一种轻量级世界-动作模型，它在紧凑的潜在空间中推理未来，并可在单个24GB GPU上进行端到端训练。其核心设计是由未来状态预测和动作生成共同塑造的紧凑潜在推理空间，这使得模型在保持轻量级的同时与控制良好对齐。对于任务规范，我们进一步提出了视觉转换标记（VTT），这是一种无语言任务表示，将每个任务编码为视觉特征空间中的一个方向。在RoboTwin 2.0、LIBERO和真实机器人任务上的实验证明了LiLa-WAM的有效性，在50个RoboTwin任务中通过单GPU训练达到了90.48%的成功率。

## Abstract
World-action modeling has emerged as a promising paradigm for robotic control, as it empowers models to go beyond reacting to observations and anticipate how a scene will evolve. However, existing WAMs often incur substantial computational overhead. Pixel-space methods often allocate substantial capacity to visual details that may not be directly relevant to control, while some latent-space methods require multi-stage training to construct the reasoning space. The resulting training cost can make such methods difficult to train under modest computational budgets. In this work, we propose LiLa-WAM, a lightweight world-action model that reasons about the future in a compact latent space and can be trained end-to-end on a single 24GB GPU. Its core design is a compact latent reasoning space jointly shaped by future-state prediction and action generation, which keeps the model lightweight while remaining well aligned with control. For task specification, we further propose the Visual Transition Token(VTT), a language-free task representation that encodes each task as a direction in visual feature space. Experiments on RoboTwin~2.0, LIBERO, and real-robot tasks demonstrate LiLa-WAM's effectiveness, achieving 90.48\% success across 50 RoboTwin tasks with single-GPU training.

- **研究背景**：世界-动作模型（World-Action Models, WAMs）通过联合建模未来状态预测与动作生成，使机器人策略能预测场景在干预下的演变，而非仅对当前观察做出被动反应。
- **现有问题**：

  - **潜在空间方法**虽避免像素级冗余，但常需多阶段训练流程（各组件分开训练后再集成到策略中），整体训练负担依然沉重；
  - 当前WAMs普遍基于大规模预训练模型（VLM或视频生成骨干），其容量大量服务于语言建模或视觉细节合成，与控制目标错配；
  - 高昂训练成本使这些方法在有限算力预算下难以使用。
- **核心目标**：在紧凑潜在空间中进行未来推理、可端到端单GPU训练的轻量级世界-动作模型，同时提供无需语言指令的视觉任务表示。

### 2. 方法论

#### 2.1 总体框架

模型学习条件分布：\(p_\theta(a_{t:t+H}, \hat{z}_{t+\Delta} \mid o_t, q_t, c_\tau)\)

- \(a_{t:t+H}\)：动作块（chunk），horizon H；
- \(\hat{z}_{t+\Delta}\)：预测的未来状态紧凑潜在表示（前瞻间隔Δ）；
- \(c_\tau\)：**Visual Transition Token（VTT）**——无语言任务表示；
- 未来不以原始观察或像素重建表示，而是由动作专家自身产生的紧凑潜在，避免重型生成骨干。

#### 2.2 架构组件（Foresight-Aware Action Expert）

| 组件 | 配置 |
|---|---|
| 视觉编码器 | 冻结的 **DINOv3-ViT-L/16**，取第17、21层特征融合 |
| 查询适配器 | 64个可学习query、4层自注意力+交叉注意力，将patch特征压缩为 \(N_q \times D\) 的压缩视觉潜在 \(Z_v\) |
| 动作专家 | 12层DiT（Diffusion-Transformer），8注意力头，特征维度768 |
| 解码器 | 4层Q-Former风格轻量解码器，仅训练时使用，推理时丢弃 |

- 输入token序列：\([Z_a; Z_q; c_\tau; Z_v]\)（动作token、本体感受token、VTT、压缩视觉潜在）；
- 输出：动作位置读出预测速度 \(\hat{v}_s\)，观察侧输出形成未来潜在 \(\hat{z}_{t+\Delta}\)；
- 未来状态预测与动作生成在同一token流内完成，梯度联合塑造一个紧凑共享潜在空间。

#### 2.3 Visual Transition Token（VTT）

- 对任务τ的每个演示片段e，取初始帧和末帧的全局图像嵌入之差，再对任务内所有片段求平均：
  \[
  u_\tau = \frac{1}{|E_\tau|} \sum_{e \in E_\tau} (g^e_T - g^e_0)
  \]
- VTT将任务编码为视觉特征空间中的"过渡方向"，即任务对场景的改动；
- 无需测试时文本或目标图像，通过轻量MLP投影注入专家网络。

#### 2.4 训练目标

\[
\mathcal{L} = \mathcal{L}_{fm} + \lambda_{ff}\mathcal{L}_{ff} \quad (\lambda_{ff}=0.5)
\]

- **\(\mathcal{L}_{fm}\)（流匹配损失）**：线性插值噪声与真实动作块，预测恒定目标速度，训练专家预测该速度；
- **\(\mathcal{L}_{ff}\)（前瞻损失）**：将预测未来潜在经训练解码器解码回DINOv3特征空间，与真实未来观察特征计算逐token余弦损失；
- 推理时不需要解码器，未来感知在单次前向传播中自然产生，**零额外推理成本**。
