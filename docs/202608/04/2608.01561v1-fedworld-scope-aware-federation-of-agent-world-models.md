## 摘要
大型语言模型（LLM）智能体从局部交互经验中学习世界动态，以支持后续的规划和动作选择。然而，单个客户端可获得的经验往往不完整，这促使跨客户端共享知识。现有的联邦方法主要聚合模型参数，而智能体记忆共享方法通常汇集轨迹、记忆或规则，却不检查这些知识对每个客户端是否仍然有效。这种假设是有问题的，因为相同的抽象动作在不同策略、环境或异常条件下可能产生不同效果。因此，大多数客户端支持的规则可能会覆盖少数客户端持有的正确知识。为解决这一问题，我们提出FEDWORLD，一种感知范围感知的联邦世界模型协议，用于交换结构化的抽象转移规则。每个客户端将私有转移转换为规范化规则，服务器对齐相关规则，以识别每个规则在客户端之间的支持证据和矛盾证据。所得证据决定规则是共享、聚类特定、私有还是未解决。每个目标客户端保留其局部规则，仅接受那些推断范围兼容的未覆盖情况的联邦更新；模糊规则被保留。在τ-bench和ALFWorld上的实验表明，FEDWORLD在冲突动态下减少负迁移，同时保留有用的跨客户端迁移，从而减少状态回退、重复动作和多余步骤，并提高任务成功率。

## Abstract
Large language model (LLM) agents learn world dynamics from local interaction experience to support subsequent planning and action selection. However, the experience available to a single client is often incomplete, which motivates sharing knowledge across clients. Existing federated methods mainly aggregate model parameters, while agent memory-sharing methods commonly pool trajectories, memories, or rules without checking whether they remain valid for each client. This assumption is problematic because the same abstract action may produce different effects under different policies, environments, or exception conditions. Consequently, a rule supported by most clients may overwrite correct knowledge held by a minority client. To address this problem, we propose FEDWORLD, a scope-aware federated world-model protocol that exchanges structured abstract transition rules. Each client converts private transitions into normalized rules, and the server aligns related rules to identify each rule supporting and contradicting evidence across clients. The resulting evidence determines whether a rule is shared, cluster-specific, private, or unresolved. Each target client retains its local rules and accepts federated updates only for uncovered cases whose inferred scope is compatible; ambiguous rules are withheld. Experiments on $τ$-bench and ALFWorld show that FEDWORLD reduces negative transfer under conflicting dynamics while retaining useful cross-client transfer, leading to fewer state regressions, repeated actions, and excess steps, as well as higher task success.

- **研究背景**：大型语言模型（LLM）智能体需要从本地交互经验中学习“世界模型”（world model），即“状态-动作-效果”的转移知识，以支持后续规划与动作选择。但单个客户端（client）的经验通常不完整，因此希望通过跨客户端共享来填补知识空缺。

- **文章定位**：作者将这一问题形式化为**范围感知的联邦世界模型（scope-aware federation of agent world models）**，主张联邦的对象应该是**离散的抽象转移规则**，而非连续模型参数或原始轨迹，并以“规则适用范围”而非“参数平均”作为联邦的核心目标。

## 2. 方法论：核心思想、关键技术细节与算法流程

**核心思想**：设计一种“本地优先、范围感知”的联邦协议 FedWorld，通过交换结构化的抽象转移规则，由服务器根据跨客户端证据推断每条规则的适用范围（共享/簇特定/私有/未解决），目标客户端仅接受与自身范围兼容且本地未覆盖的规则，避免用不兼容的多数规则覆盖本地正确知识。

**关键技术细节**：

- **M1：抽象规则映射（Abstract Rule Mapping）**
  - 每个客户端将私有详细转移 `(state_pre, action, condition, state_post)` 通过归一化映射 `ϕ_k` 转换为抽象规则 `z = (a, x, c, e, ε)`（动作类型、归一化前状态、条件集、抽象效果、异常结构）。
  - 原始轨迹、实体标识、详细状态等均保留在本地，只共享抽象规则。
  - 规则身份键：`key(r) = (Norm(S_pre), Norm(A), Norm(C))`。

- **M2：跨客户端规则对齐（Cross-Client Rule Alignment）**
  - 对目标规则与候选规则标注关系：`match`（匹配）、`compatible`（兼容）、`conflict`（冲突）、`unresolved`（未解决）。
  - 仅 `match` 和 `compatible` 规则进入后续范围推断，避免仅凭相似性直接采用（区别于传统最近邻检索）。

- **M3：范围推断（Scope Inference）**
  - 基于每个候选规则的支持证据数 `n⁺` 与矛盾证据数 `n⁻`，计算 Laplace 平滑置信度 `q_r = (n⁺+1)/(n⁺+n⁻+2)`。
  - 同时计算客户端级别比例：`p_r = |K⁺_r|/|K^{eligible}_r|`、`ρ⁻_r = |K⁻_r|/|K^{eligible}_r|`（分母为可发生该前置条件的客户端集合，避免无关客户端被惩罚）。
  - 将规则分类为：`shared`（共享）、`cluster`（簇特定）、`private`（私有）、`unresolved`（未解决）；`unresolved` 规则保留在联邦库中但不参与执行。

- **M4：缺口检测与编译（Gap Detection and Compilation）**
  - 本地优先策略：若目标客户端已有该规则的本地规则且置信度 `κ_k(u) ≥ τ_loc`，则直接采用本地预测，不咨询联邦。
  - 否则，从目标兼容候选集 `F_FW(k,u)` 中选择规则，按“关系类型、范围特异性、置信度 `q_r`”排序，并由编译器将抽象效果转换为目标客户端可执行指令。
  - 若无任何候选通过过滤，则回退本地备用规则或放弃（abstain）。
  - 算法流程（Algorithm 1）：输入本地库、联邦库、目标客户端和查询规则；若本地命中则返回本地预测；否则遍历候选并推断范围、过滤兼容项；有兼容候选则编译返回，否则本地回退/放弃。

## 3. 实验设计

- **数据集 / 场景**：

  - **ALFWorld**：文本家庭环境基准，动作效果随对象状态、容器约束和环境布局变化。构建 **12 个客户端**（不同家庭转移配置）。
- **Benchmark 特点**：覆盖“政策依赖型”和“环境依赖型”两类转移冲突。

- **对比方法**：

  - B4：有对齐但无范围兼容检查
  - B5：完整 FedWorld

## 6. 主要结论与发现

- **本地知识有用但不完整**：B1 在 S0 上准确率高，但在 S3 上显著下降（τ-bench 从 0.846→0.712，ALFWorld 从 0.812→0.574），证明跨客户端共享的必要性。
- **范围过滤保留正迁移并避免负迁移**：B5 相比 B1 在 S3 上提升 12.4 点（τ-bench）和 21.2 点（ALFWorld）；在 S5 上提升 12.2 和 20.0 点。
- **朴素共享在冲突动态下有害**：B3 在 S4strict 上显著低于 B1（τ-bench 0.556 vs 0.694；ALFWorld 0.431 vs 0.653），而 B5 恢复到 0.722 和 0.681，比 B1 还略高 2.8 点。
- **负迁移主要由“多数规则覆盖少数正确知识”引起**：B3 的净迁移为 −0.138（τ-bench）和 −0.222（ALFWorld），B5 则转为 +0.028（两者均）。
- **在线性能明显改进**：相比 B1，B5 减少状态回归 44.5%（τ-bench）和 48.2%（ALFWorld）；重复动作减少约 48–50%；多余步骤减少约 38–43%；任务成功率提高 11.2 和 14.6 个百分点。
- **稳定性良好**：B5 的优势在 5 个种子上方向一致，方差未扩大。
- **CDR 并不优于 FedWorld**：即使访问详细池化记录，若不能按目标客户端过滤范围，仍可能因检索到客户特定转换而失败，说明“数据更多”不能替代“目标条件化范围控制”。
