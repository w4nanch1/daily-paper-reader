## 摘要
接触丰富的操作仍然具有挑战性，因为成功的控制依赖于物理交互线索，而这些线索通常仅凭视觉难以充分观察。最近的触觉世界动作模型联合建模未来的视觉观测和触觉信号以指导动作生成，但如何构建这些未来以供动作专家有效使用仍未得到充分探索。直接使用学习到的世界动作模型来研究这个问题是困难的，因为端到端行为将物理上无效的视觉未来、不可靠的预测、不准确或跨模态不一致的触觉预测以及难以解读的未来到动作接口纠缠在一起。为了使该接口能够独立研究，我们引入了Oracle视觉-触觉预见（OVTF），这是一个受控框架，从模拟中验证的成功轨迹提供配对的RGB和触觉未来。通过固定未来提供者，OVTF隔离了该接口，并提出一个更清晰的问题：如果未来是成功且物理可执行的，那么何种表示能让动作专家吸收其益处？在OVTF中，我们提出了非对称相位局部未来记忆（AFM），其中视觉记忆读取未来视觉，每个触觉记忆共同关注自身的触觉流和相位对齐的未来视觉，并阻断跨触觉访问。我们将AFM与模态隔离未来记忆（IFM）进行比较，后者消除了视觉到触觉的访问，并独立处理每种未来模态。在UniVTAC模拟基准的七个任务中，AFM实现了32.0%的平均成功率，而IFM为23.7%，UniVTAC-ACT为14.9%。这一受控比较表明，选择性的相位对齐视觉-触觉路由比完全模态隔离提供了更可操作的未来到动作桥梁。

## Abstract
Contact-rich manipulation remains challenging because successful control depends on physical interaction cues that are often weakly observable from vision alone. Recent tactile world action models jointly model future visual observations and tactile signals to guide action generation, but how such futures should be structured for effective use by the action expert remains underexplored. Directly studying this question with learned world action models is difficult because end-to-end behavior entangles physically invalid visual futures, unreliable predictions, inaccurate or cross-modally inconsistent tactile forecasts, and an unreadable future-to-action interface. To make this interface independently studyable, we introduce Oracle Visuo-Tactile Foresight (OVTF), a controlled framework that supplies paired RGB and tactile futures from successful trajectories verified in simulation. By fixing the future provider, OVTF isolates the interface and asks a cleaner question: if the future is successful and physically executable, what representation allows the action expert to absorb its benefit? Within OVTF, we propose Asymmetric Phase-Local Future Memory (AFM), in which visual memory reads future vision, each tactile memory jointly attends to its own tactile stream and phase-aligned future vision, and cross-tactile access is blocked. We compare AFM with Modality-Isolated Future Memory (IFM), which removes visual-to-tactile access and processes each future modality independently. Across seven tasks on the UniVTAC simulation benchmark, AFM achieves 32.0% average success, compared with 23.7% for IFM and 14.9% for UniVTAC-ACT. This controlled comparison shows that selective phase-aligned visual-tactile routing provides a more actionable future-to-action bridge than complete modality isolation.

## 1. 核心问题与研究动机

- **问题背景**：接触丰富的操作任务（如插拔、抓取、放置等）中，控制成功高度依赖物理交互线索（接触时序、力反馈、形变等），这些线索仅凭视觉往往难以充分观察。因此，近年来的触觉世界动作模型（Tactile World Action Models）尝试联合预测未来视觉观测与触觉信号，以辅助动作生成。
- **核心困难**：即便有了未来预测，也存在一个关键瓶颈——**未来信息到动作生成的“接口”（interface）设计**。即：未来的视觉-触觉信息以何种表示形式传递给动作专家，才能被高效利用？
- **研究障碍**：直接研究该问题极为困难，因为端到端世界动作模型的最终任务分数会纠缠四种效应：
  1. 物理上无效的视觉未来（违反接触力学或不可执行）；
  2. 动作分支对不可靠预测的信任不足；
  3. 触觉未来预测不准确或与视觉跨模态不一致；
  4. 未来信息编码形式本身对动作分支不可读。
- **论文的核心思路**：既然这四种效应混杂在一起，不如**显式隔离未来提供者（future provider）与未来到动作接口**——即：如果未来信息本身是成功且物理可执行的，剩下唯一的问题是接口应如何设计。这就是本文提出 **OVTF（Oracle Visuo-Tactile Foresight）** 框架的核心逻辑。

## 2. 方法论

### 2.1 OVTF 框架思想

- **核心思想**：不采用学习式预测器生成未来信息，而是直接从模拟中验证过（simulation-verified）的成功示范轨迹中采样配对的 RGB 和触觉未来。这样可以：
  - 消除预测器误差的干扰；
  - 保证未来是成功且物理可执行的；
  - 将“未来提供”与“未来消费接口”解耦，使接口可独立研究。
- **清晰的研究问题**：如果未来信息是成功且物理可执行的，什么接口能让动作专家充分发挥其价值？

### 2.2 未来信息来源

- 从当前初始化对齐的成功示范轨迹中，以参考帧 τ_ref 为起点，均匀采样至多 N=100 帧未来帧（含视觉与左右触觉 RGB 图像）。
- 定义归一化相位：
  \[
  φ_i = (τ_i − τ_{ref}) / max(1, T − 1 − τ_{ref}), φ_i ∈ [0,1]
  \]
- 约定：Oracle 未来来源**仅提供参考轨迹的图像**（RGB + 左右触觉），不提供未来动作、未来 qpos、物体位姿、模拟器状态或成功标签等任何特权元数据。

### 2.3 未来编码器

- 每个未来视觉帧和触觉帧由**可训练的 ResNet-18** 编码，初始化为复制 UniVTAC-ACT* 的预训练编码器权重。
- 编码后得到三条序列：H（视觉）、L（左触觉）、R（右触觉），均为 N×512 维。
- 每条序列通过**门控局部时间残差**处理：
  \[
  X′_m = X_m + tanh(g_m)·DepthwiseConv1d(LN(X_m))
  \]
  其中门控初始化为零，保证训练初期不干扰已有表示。
- 对于双相机任务（Insert Tube 和 Lift Can），头相机与腕相机图像分别编码后用两层 MLP 融合为 512 维 H 流。

### 2.4 AFM：非对称相位局部未来记忆

- **12 个可学习槽位**：4 个视觉槽 + 4 个左触觉槽 + 4 个右触觉槽，每个 512 维。
- 各模态使用**固定相位锚点**：C = {0.125, 0.375, 0.625, 0.875}。
- 注意力计算中加入**高斯相位先验**（软约束，非硬窗口）：
  \[
  score_{hk,i} = \frac{q_{hk}^T k_{hi}}{\sqrt{64}} − \frac{(φ_i − c_k)^2}{2×0.18^2}
  \]
- **AFM 路由规则**：
  - 视觉记忆读取未来视觉：H ← H；
  - 左触觉记忆联合读取自身触觉 + 相位对齐的未来视觉：L ← (L, H)；
  - 右触觉记忆联合读取自身触觉 + 相位对齐的未来视觉：R ← (R, H)；
  - **阻断左右触觉互读**：L ↔ R 禁止访问。
- **IFM（对比方法）路由规则**：H←H，L←L，R←R，完全模态隔离。

### 2.5 ACT 集成与训练目标

- 当前观测用冻结的 UniVTAC-ACT* 编码器处理，qpos 用冻结状态投影处理，构成当前空间记忆。
- 未来槽通过零初始化的 tanh 门控后，与当前记忆拼接到 ACT 编码器记忆中，动作查询通过 Transformer 解码器读取。
- 训练目标为**掩码动作 L1 损失**；禁用 CVAE，潜变量 z 始终为零。
- 可训练部分：未来编码器、时间滤波、槽位读取器、ACT Transformer 与动作头。当前编码器冻结。

## 6. 主要结论与发现

1. **AFM Oracle 平均成功率 32.0%**，显著高于 IFM（23.7%）与 UniVTAC-ACT*（14.9%），证明成功且物理可执行的未来信号确实能为接触丰富的动作生成提供重要指导。
2. **AFM 与 IFM 之间 8.3 个百分点的差距**证明：即使在 ACT 编码器内后续可以重新自注意力交互，**接口层的显式非对称视觉-触觉融合**仍比完全模态隔离更有利于动作生成——下游注意力无法从隔离接口中恢复全部信息。
3. **Oracle 与 Forced-Zero 的对比**（32.0% vs 19.4%）说明模型**确实在测试时使用了未来内容**，而非仅从新增模块中获益。
4. **AFM Zero-Train（20.0%）与 Forced-Zero（19.4%）均超过 UniVTAC-ACT*（14.9%）**，说明 AFM 兼容的策略路径在没有未来信息时依然稳健，框架本身不依赖未来输入。
5. **任务层面的补充发现**：Put Shelf 和 Pull Out Key 最能体现未来信息的价值（Oracle 分别为 54% 和 54%，相对基线提升最大）；Insert Tube 中 Oracle 与 Forced-Zero 同为 42%，说明该任务的优势部分来自策略路径本身而非未来输入。

## 7. 优点与亮点

- **问题拆解视角新颖**：不是继续堆叠更好的预测器，而是将“未来预测”与“未来消费接口”解耦，提出了更本质的研究问题。这在世界动作模型领域具有方法论贡献。
- **OVTF 框架设计巧妙**：用 Oracle 成功轨迹替代学习式预测器，使接口研究不再受预测误差污染，也保证了未来信息是物理可执行的上界参考。
- **受控对比严格**：AFM、IFM、Zero-Train、Forced-Zero 四条件之间只改变一个变量，归因清晰，结论可信度较高。
- **AFM 机制具有实际价值**：非对称路由（视觉可引导触觉、触觉间互斥）符合物理直觉——视觉提供全局上下文，触觉提供局部接触细节，左右手触觉各自独立，这种结构有可解释性。
- **软相位先验设计**：用高斯分布做软约束而非硬窗口，兼顾相位对齐的意图与内容检索的灵活性。

## 8. 不足与局限

- **仅限仿真，无真实世界验证**：所有实验均在 UniVTAC 模拟环境中完成，且未做 sim-to-real 迁移评估。实际物理系统中触觉信号噪声、延迟和分布偏移可能显著改变接口设计的结论。
- **统计显著性未知**：每任务 50 次 rollout、未报告多随机种子方差和置信区间，任务间差异较大时（如 Lift Can 0% vs Oracle 30%）难以判断结论的统计稳健性。
- **Oracle 前提过于理想**：OVTF 依赖模拟中验证的成功轨迹作为未来来源，这意味着需要预知“成功未来的样子”，在实际部署中不可用。论文将其定位为诊断性工具，但该设定与“世界模型”的预测功能仍有距离。
- **训练充分性存疑**：仅 2000 步训练且无多种子结果；某些任务成功率接近底部（Insert Hole 最高 8%、Lift Bottle 16%），可能受偶然性影响较大。
- **未与更广泛的 WAM 方法对比**：只比较了 AFM/IFM 与 UniVTAC-ACT* 基线，未与现有触觉 WAM（如 DreamTac、VT-WAM 等）做端到端比较。因此论文声称的“接口优势”是在受控框架内的结论，不能直接外推为完整的端到端系统优势。
- **模型规模与结构较基础**：基于 ACT 策略与 ResNet-18 编码器，未探索更强大的骨干网络或更大规模的未来记忆容量，结论的泛化性仍需更多架构验证。
