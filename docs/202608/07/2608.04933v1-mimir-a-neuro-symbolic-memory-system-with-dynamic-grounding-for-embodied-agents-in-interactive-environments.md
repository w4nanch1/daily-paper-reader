## 摘要
长时程具身任务要求智能体在部分可观测性下行动，同时保持场景信念和执行进度。扁平历史或隐式策略状态可能包含过去的观测，但它们并未提供显式接口来决定哪些世界事实支持当前活动目标。我们引入了Mimir，一种神经符号记忆系统，将世界记忆与任务记忆分离，并在每次行动前动态接地。世界记忆维护对象位置、对象状态和感知证据，而任务记忆维护有序目标议程、进度状态、手部状态、失败和执行约束。接地模块将活动目标绑定到回忆的世界候选，填补缺失的来源位置，并在规划和具身特定执行前附加证据。在测试的不同骨干网络上，Mimir在EB-ALFRED和EB-Habitat的不同任务上持续改进，最大提升42.5%，平均提升23.0%。与在同一骨干下评估的先前智能体和记忆系统的最佳结果相比，Mimir将整体平均成功率提高了8.5%。最后，在EB-Habitat长时程子集上，Mimir实现了86.0%的成功率，显著优于当前的闭源模型。我们的代码即将发布。

## Abstract
Long-horizon embodied task requires agents to act under partial observability while preserving both scene belief and execution progress. Flat histories or implicit policy states may contain past observations, but they do not provide an explicit interface for deciding which world facts support the currently active goal. We introduce Mimir, a neuro-symbolic memory that separates world memory from task memory and dynamically grounds them before each action. World memory maintains object locations, object states, and perceptual evidence, while task memory maintains an ordered goal agenda, progress state, hand state, failures, and execution constraints. A grounding module binds the active goal to recalled world candidates, fills missing source locations, and attaches evidence before planning and embodiment-specific execution. Across tested backbones, Mimir consistently improves on different EB-ALFRED and EB-Habitat tasks, with maximum gains of 42.5% and average gains of 23.0%, respectively. Compared with the best results among prior agent and memory systems evaluated under the same backbone, Mimir improves the overall average success rate by 8.5%. Finally, on the EB-Habitat Long-horizon subset, Mimir achieves 86.0% success rate, substantially outperforming current closed-source models. Our code will be released soon.

## 1. 核心问题与研究动机

本论文针对**长时程具身操作任务**中的核心挑战：智能体在部分可观测环境中行动，需要在持续的交互过程中同时维护**场景信念**（世界状态）与**执行进度**（任务状态），才能支撑后续决策。

- **部分可观测性**：相关物体可能离开视野、改变状态，或只能通过早期交互来识别，当前观测不足以选择下一步动作。
- **现有方法的不足**：
  - 扁平历史（flat history）能保留过去帧，却不暴露可操作的状态——如物体是否仍在容器中、是否被拿起、子目标是否已完成。
  - 长提示或隐式策略状态虽可保存信息，但缺乏**显式接口**用于查看、更新和复用信息。
  - LLM-State、CA-PEAM 等记忆系统虽增强了世界状态追踪，但任务进度仍隐式，且未将回忆证据绑定到活动目标。
  - 记忆与执行之间存在"缺失的操作链接"：智能体知道什么与下一步必须完成什么之间缺乏直接接口。

这一研究的核心含义是：**具身记忆不应只是被动存储历史，而应该成为一个显式的在线决策状态接口**，将世界事实与当前活动目标动态绑定。

## 2. 方法论

### 2.1 核心思想

Mimir 将记忆形式化为**世界记忆**与**任务记忆**的协同演化，并通过**动态接地**（dynamic grounding）在每次行动前将两者连接起来。采用符号化的数据结构（TreeMemory），但依赖大模型的感知与决策能力进行更新和推理，因此称为"神经符号"系统。

### 2.2 记忆结构

- **任务记忆** T_t = (G, ⪯, s_t, h_t, F_t, C_t)：
  - G：符号化目标集合
  - ⪯：目标之间的议程顺序（前置条件优先，任务顺序作为确定性平局打破规则）
  - s_t：目标状态映射（pending / completed / blocked）
  - h_t：当前手部状态（held object）
  - F_t：已失败的对象–来源假设
  - C_t：对已完成目标的支持证据
  - 活动目标为当前 pending 集中顺序最前者

- **世界记忆** W_t = (V_t, E_t, r, ℓ_t, φ_t)：
  - V_t：场景实体集合；E_t：父子关系；r：场景根节点
  - ℓ_t：语义标签；φ_t：属性与证据存储
  - 每个实体有一个"活动父节点"（所在的房间、支撑面、容器或手中状态）；不确定的候选以分离假设保存
  - 证据存储保留每个记录的来源（观测或交互反馈），使后续决策能区分观测到的关系与执行反馈支持的关系

- **两记忆分离的原因**：它们由不同证据驱动演化——观测和交互效果修改世界记忆，执行结果修改任务记忆。这种分离使接地操作有稳定的任务侧查询，即使世界表示持续变化。

### 2.3 动态更新机制

- 观测更新 (U_obs^W)：添加新实体或在身份与关系上下文一致时细化假设；同名实例或不相容关系保留为分立假设。
- 动作更新 (U_act^W)：仅写入反馈支持的改变（拾取、放置、状态变化等）；失败动作不改变物理关系，被矛盾化（contradicted）的绑定记录到任务记忆的失败集合 F_t。
- 任务更新 (U_T)：动作成功≠目标完成——仅当反馈效果建立目标的后置条件 Post(g, Δ_t)=1 时才标记完成。

### 2.4 动态接地与执行流程

算法 1 描述了闭环推理流程：

1. 观测更新世界记忆 → 选择活动目标 → 目标条件检索返回有界候选列表 R_t
2. 接地操作 G：
   - 过滤：排除不能支持合法交互、与显式源/目标约束冲突、或已被反馈矛盾化的候选
   - 选择：挑选当前观测与回忆证据支持度最高的候选
   - 补全：若指令未指定来源，从候选实体的记忆父节点补全
   - 输出元组：ĝ_t = (g_t, v*_t, u*_t, d*_t, η*_t) —— 目标、绑定对象、来源、目标位置、支持证据
   - **Fail-closed 设计**：若无候选满足约束则返回 ⊥_grd，不将不确定的记忆查询转化为可执行动作
3. 在具身无关的抽象动作空间规划，通过适配器 ρ_e 映射为合法动作
4. 若适配失败则 Replan；若接地失败则进入探索模式（Explore）
5. 执行后反馈同时更新世界记忆与任务记忆，循环往复

## 6. 主要结论与发现

1. **一致性的性能提升**：Mimir 在所有 13 个骨干、两个 benchmark 上同时提升 SR 和 GC。最大增益：EB-ALFRED 上 InternVL3-8B 提升 42.5 个 SR 点；EB-Habitat 上 Gemma-3-12B 提升 37.5 个 SR 点、42.6 个 GC 点。平均 SR 增益约 23.0%。
2. **显式记忆可补偿骨干容量不足**：InternVL3-8B + Mimir 的 SR/GC 可与 38B/78B 骨干相比，说明结构化状态管理能弥补模型规模劣势；但 Qwen3-VL-32B 仍强于 8B，说明骨干容量与记忆结构互补而非可互换。
3. **同骨干对比超越现有系统**：与 RoboMemory 相比，EB-Habitat SR 提升 16.0 点、GC 提升 13.6 点；整体平均成功率比最佳基线提高 8.5%。
4. **超越闭源模型**：Qwen3-VL-32B + Mimir 在 EB-Habitat Long-horizon 上达到 86.0% SR 和 93.0% GC，超过最强闭源基线（Gemini-3.5-Flash 的 80.0/84.8）。
5. **世界记忆与任务记忆分工明确**：EB-Habitat 上移除世界记忆导致 SR 暴跌至 12.5（8B 和 32B 均如此）；EB-ALFRED 上移除任务记忆损失更大（8B 下降 23.0 点，32B 下降 37.5 点）。两者耦合时效果最佳。
6. **Instruct 优于 Thinking 模式（在 Mimir 下）**：一旦任务进度和世界证据外部化，Instruct 模型能更直接地利用接地的决策状态；Thinking 模式的额外内部推理不再提供优势，甚至更弱。

## 9. 总体评价与展望

总体而言，Mimir 是一篇方法动机明确、系统设计完整、实验规模扎实的具身记忆工作。它的核心贡献不在于提出新的 VLM 或强化学习算法，而在于重新定义了“记忆”在具身智能体中的角色：从被动的历史缓存，转变为主动的、显式的、可验证的在线决策状态。通过将世界事实与任务进度分离并动态接地，Mimir 有效弥补了现有记忆系统与执行决策之间的操作空缺，并展示了跨 13 个骨干的稳定增益。

从实用性角度看，该系统的最大价值在于**无需训练即可增强任意现有 VLM 骨干**，且只在推理时引入可控的记忆维护成本，因此具备较强的即插即用潜力。未来值得探索的方向包括：将记忆结构进一步扩展到多智能体协作场景；设计更鲁棒的感知错误检测与记忆回滚机制；在真实机器人平台上验证记忆更新与动作执行之间的延迟与物理反馈噪声问题；以及更深入地分析外部显式记忆与模型内部推理能力之间的互补边界。

如果后续工作能补充真实硬件实验、更细粒度的失败统计以及更大范围的消融分析，Mimir 的方法体系有望成为具身智能体长期记忆设计的基准参考之一。
