## 摘要
持续改进的智能体需要超越静态监督的动态交互反馈，然而直接与真实环境交互成本高昂、速度缓慢、存在安全风险且难以并行化。世界建模提供了一种自然的中间代理，使智能体在采取真实行动之前能够查询更低成本、更可控的反馈。经典世界模型主要通过未来物理状态预测来实例化这种代理，这种形式对需要超越原始状态转换的可操作反馈的智能体而言虽有用但过于狭窄。在这项工作中，我们概念化了智能体为中心的交互式世界代理，将基本范式从物理状态转换转向智能体可用的信息转换，例如执行结果、检索到的经验或技能以及验证信号，从而拓宽世界建模的范围，为持续改进的智能体提供多功能的反馈。为了系统性地映射这一设计空间，我们根据反馈模态将世界代理组织为六种功能形式：动力学代理、空间代理、执行代理、记忆/经验代理、技能代理以及奖励/验证代理，它们共同刻画了世界建模服务于智能体改进的主要方式。我们进一步分析了这些代理如何在三个递进层面上赋能智能体：L.1 推理时引导，代理输出丰富上下文信息以产生更优决策；L.2 训练时优化，代理输出产生奖励、批评或合成轨迹用于策略学习；L.3 智能体-代理共同演化，真实环境证据不断更新代理和智能体以实现共同演化。最终，这项工作将世界建模重塑为智能体中心的范式，为构建能够赋能智能体更好地规划、更快学习并持续演化的世界代理建立了路线图。

## Abstract
Continually improving agents require dynamic interaction feedback beyond static supervision, yet direct real-environment interaction is costly, slow, unsafe, and hard to parallelize. World modeling offers a natural intermediate proxy that allows agents to query lower-cost, more controllable feedback before committing to real actions. Classical world models instantiate this proxy primarily through future physical-state prediction, a formulation useful yet narrow for agents that require actionable feedback beyond raw state transitions. In this work, we conceptualize Agent-Centric Interactive World Proxies, shifting the fundamental paradigm from physical state transitions to agent-usable information transitions, such as execution outcomes, retrieved experiences or skills, and verification signals, broadening the scope of world modeling to provide versatile feedback for continually improving agents. To systematically map this design space, we organize world proxies into six functional forms based on their feedback modalities: dynamics, spatial, execution, memory/experience, skill, and reward/verification proxies, which together characterize the primary ways world modeling serves agent improvement. We further analyze how these proxies empower agents across three progressive levels: L.1 Inference-Time Guidance, where proxy outputs enrich in-context information for superior decisions; L.2 Training-Time Optimization, where proxy outputs yield rewards, critiques, or synthetic rollouts for policy learning; and L.3 Agent-Proxy Co-Evolution, where real-environment evidence continuously updates both the proxy and the agent for co-evolution. Ultimately, this work recasts world modeling into an agent-centric paradigm, establishing a roadmap for building world proxies that empower agents to plan better, learn faster, and evolve continually.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：提出**智能体中心交互式世界代理**（Agent-Centric Interactive World Proxies）概念。
  - **范式转变**：从物理状态转移（physical state transition）转向**信息转移**（information transition）。世界代理的输出不再是仅仅预测下一个物理状态，而是更广义的“信息”，如执行结果、检索的经验、技能、验证信号等。
  - **概念定义**：智能体中心世界代理被定义为“一种基于环境（environment-grounded）的代理，它建模或预测**以智能体发起的交互为条件的信息转移**，旨在为智能体改进提供信息增益”。
  - **形式化表述**：$\hat{s}_{\ell+1} = \mathcal{WP}(s_\ell, u^\mathcal{F}_\ell)$，其中：
    - $\ell$ 表示**交互步骤**（不限于物理时间步）；
    - $s_\ell$ 属于广义的**信息状态空间**（$\mathcal{S}$）；
    - $\mathcal{F}$ 代表特定的代理功能（如动力学、空间、执行等）；
    - $u^\mathcal{F}_\ell$ 是智能体主动发起的查询、动作或干预；
    - $\hat{s}_{\ell+1}$ 是代理返回的反馈（未来状态、新观察、执行结果、检索记忆/技能、奖励或验证结果）。

- **关键技术细节与理论框架**：
  1. **从 “World Model” 到 “World Proxy” 的转变**：沿三个轴拓展经典定义——
     - 物理时间步（$t \rightarrow t+1$）→ 交互步骤（$\ell \rightarrow \ell+1$），代理交互不总是推进物理时间。
     - 状态转移（$s_t \rightarrow \hat{s}_{t+1}$）→ 信息转移（$s_\ell \rightarrow \hat{s}_{\ell+1}$），输出可以是任何类型的智能体可用信息。
     - 外部条件 → 智能体发起的交互，交互由智能体根据目标主动提出。
  2. **六种功能性代理（Proxy Function）**：根据反馈模态将世界代理划分为六种形式：
     - **动力学代理（Dynamics Proxy）**：预测未来状态和奖励，即经典世界模型。
     - **空间代理（Spatial Proxy）**：生成特定视角或空间位置下的观察结果。
     - **执行代理（Execution Proxy）**：模拟代码、命令、网页点击、API调用等可执行交互的结果。
     - **记忆/经验代理（Memory/Experience Proxy）**：检索与当前任务相关的过往经验、失败案例或约束。
     - **技能代理（Skill Proxy）**：检索或推荐可复用的行为策略、工具使用例程。
     - **奖励/验证代理（Reward/Verification Proxy）**：评估智能体行为、轨迹或计划，提供奖励、批评、偏好或验证信号。
  3. **三个赋能层级（Three Empowerment Levels）**：
     - **L.1 推理时引导（Inference-Time Guidance）**：世界代理仅作为上下文增强器，在推理时提供记忆、技能、模拟或验证反馈，丰富智能体的上下文，使其“看得更多、推理更准、行动更稳”，但不改变其参数。
     - **L.2 训练时优化（Training-Time Optimization）**：世界代理作为“奖励模型”、“批评家”、“验证器”或“模拟器”，生成的信号作为SFT、DPO、PPO/GRPO等训练目标，直接重塑智能体策略，提升其能力上限。
     - **L.3 智能体-代理共同演化（Agent-Proxy Co-Evolution）**：真实环境的证据持续回流，更新世界代理；世界代理的知识又通过蒸馏等方式内化为智能体的能力，实现“代理→智能体”和“智能体→代理”的双向更新，形成持续改进的闭环。
