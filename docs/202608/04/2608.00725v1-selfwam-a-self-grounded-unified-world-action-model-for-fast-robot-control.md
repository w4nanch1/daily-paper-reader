## 摘要
世界动作模型（WAM）通过联合建模动作和未来观测来改进机器人策略学习。然而，仅以任务提示和观测上下文为条件进行未来预测，可能会捕获通用的任务进展，而非所执行动作的具体后果。我们提出了SelfWAM，一种基于模态专用混合变换器（MoT）架构的统一自接地WAM，它同时预测动作、动作条件下的未来RGB帧和机器人自掩码，从而将未来预测植根于机器人可见身体及其动作引起的运动。在联合训练期间，SelfWAM允许未来视觉查询关注演示动作的干净副本，将视频分支转变为动作特定的后果模型，同时保持仅动作的快速推理路径不变。为了将视频学习集中在与动作相关的视觉变化上，我们使用针对未来机器人自掩码预测的提示特定目标，这消除了外观细节，并提供了一个其时间演变与条件动作紧密耦合的目标。干净动作条件化和未来自掩码监督共同使未来预测更直接地反映所执行动作如何改变机器人的可见运动和周围场景。在RoboTwin 2.0和真实世界操作任务上的实验表明，SelfWAM产生对动作更敏感的未来，并保持快速的策略推理，同时提高策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

# SelfWAM：一种用于快速机器人控制的自接地统一世界动作模型

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：世界动作模型（WAM）通过联合建模动作与未来观测来改进机器人策略学习，已在多个工作中得到验证（如 FastWAM、GigaWorld-Policy 等）。
- **核心问题**：现有 WAM（尤其 FastWAM）的未来视频预测仅以当前观测、任务提示为条件，并没有显式建模"哪个动作导致了哪个未来"。这种动作无关的辅助目标容易让模型学到通用的任务进展模式，而非动作特定的因果后果。对于一个操作任务，同一观测下可能存在多个合法动作，各自的未来演变不同，仅靠观测无法区分。

- **核心主张**：未来预测应当"自接地"（self-grounded），即显式建模机器人可见身体及其动作诱导的运动。为此，需要将未来预测与具体执行的动作对齐，并将学习信号聚焦在与动作相关的机器人与场景变化上。

> 一句话概括：SelfWAM 通过"动作条件化的未来预测 + 机器人自掩码监督"，把世界模型从被动的旁观者转变为主动的、能区分动作后果的"执行者"，同时保持快速的动作推理路径。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 整体架构

- **基础架构**：基于 FastWAM 的模态特化双流 MoT（Mixture-of-Transformers）架构，由以下部分组成：
  - **视频骨干（video backbone）**：初始化自预训练视频生成模型 WAN2.2-5B，处理当前观测的编码与未来视频的噪声潜在表示。
  - **轻量动作专家（action expert）**：初始化自同一 WAN2.2-5B 检查点的参数插值，处理含噪的动作 token。
  - **混合注意力（mixed attention）**：控制各 token 组之间的信息交换方向，两组专家保留各自的模态专用投影和前馈网络。

### 2.2 核心创新一：干净动作条件化（Clean-Action Conditioning）

- **动机**：让未来视频预测显式依赖产生该未来的演示动作。
- **具体实现**：
  - 对同一动作块创建两个副本：一个带噪副本用于动作去噪训练；一个干净副本作为视觉模型的条件。
  - 干净副本使用与带噪动作 token 相同的动作 tokenizer、动作块和时序位置编码，但分配去噪时间步 t=0，以区分"干净条件"与"去噪状态"。
  - 信息流设计（非对称注意力模式）为：
    - 带噪动作查询 → 只能关注当前上下文 + 自身带噪动作 token：`Q_eA → {O, eA}`
    - 未来视频查询 → 可以关注当前上下文 + 自身视频 token + 干净动作 token：`Q_eV → {O, eV, A}`
    - 干净动作查询 → 只能关注当前上下文 + 自身干净动作 token：`Q_A → {O, A}`
  - 这一设计保证了三点：
    1. 视频分支能利用干净动作信息，区分不同动作导致的未来差异；
    2. 策略分支（带噪动作查询）无法获取清理动作和未来视觉信息，防止目标泄漏（leakage）；
    3. 部署时策略推理流程与动作-only 推理完全一致，计算图不变。

### 2.3 核心创新二：未来机器人自掩码预测（Future Robot Self-Mask Prediction）

- **动机**：RGB 预测受物体外观、纹理、光照、背景等因素干扰，许多视觉细节与动作无关，可能主导学习目标。自掩码（robot self-mask）能去除外观变化，聚焦机器人在场景中的可见运动。
- **实现方式**：
  - 同一视频骨干被复用于两个输出域：RGB 视频预测和机器人自掩码视频预测。
  - 同一演示生成两个训练实例，共享观测、指令、本体感觉、干净动作条件，仅输出提示（prompt）和未来目标不同：
    - RGB 实例：提示为"A video recorded from a robot's point of view..."，目标为未来 RGB 帧；
    - 自掩码实例：提示为"A robot-arm mask video..."，目标为未来的二值机器人分段视频。
  - 两种输出共享相同的时空 token 布局、噪声调度、位置编码和注意力模式，因此自掩码预测被视为同一视频模型的第二个输出域，而非独立专家。
  - 自掩码实例不包含动作监督（无带噪动作目标），只贡献视觉损失。
- **采样比例**：RGB 实例与自掩码实例的采样比例为 9:1。

### 2.4 训练与推理

- **训练目标**（基于 flow-matching）：
  \[
  \mathcal{L} = \lambda_{\text{act}}\mathcal{L}_{\text{act}} + \lambda_{\text{video}}\mathcal{L}_{\text{rgb/mask}}
  \]
  其中 \(\lambda_{\text{act}} = 1\)，\(\lambda_{\text{video}} = 1\)，\(\mathcal{L}_{\text{rgb/mask}}\) 是 RGB 与自掩码视频去噪损失的混合期望。
- **部署推理**：只走动作-only 路径——编码当前上下文 → 用动作专家迭代去噪动作块 → 执行前 24 个动作 → 重规划。干净动作和未来视频 token 均不实例化。
- **可选的世界模型 rollout**：如果需要诊断或反事实生成，可插入候选动作到干净动作通道，并通过输出提示选择生成未来 RGB 或自掩码视频。

## 6. 主要结论与发现

1. **动作条件化显著改善未来预测质量**：与观测条件化相比，干净动作条件化使 LPIPS 降低、PSNR 提升、FVD 降低，说明条件化未来预测确实将视频分支转化为动作特定的后果模型。
2. **自掩码监督是提升策略性能的关键增量**：单加动作条件化对策略性能有小幅负面影响，但自掩码监督将其转化为显著的正增益（+1.82%，平均成功率），并提高了随机化环境中的鲁棒性。
3. **动作敏感性与方向对齐得到验证**：SelfWAM 能在固定观测与噪声下，随动作扰动方向移动预测的自掩码，且响应随插值系数连续变化，而动作无条件基线几乎不变。
4. **部署效率几乎不受影响**：动作-only 推理只增加 0.97% 延迟，峰值内存不变，满足了快速闭环控制的需求。
5. **自接地未来预测兼容高效策略学习**：训练时加入世界模型目标不需要牺牲策略路径的计算图结构，训练后的策略可以直接部署。

## 7. 优点与亮点

1. **方法论亮点——非对称信息流设计**：干净动作副本只暴露给未来视频查询，策略查询无法访问该信息，从根本上防止了目标泄漏，同时让世界模型获得"动作→后果"的因果信息。这是一个设计简洁

这一受限信息流设计在工程上几乎零成本地嵌入 FastWAM 的双流 MoT 架构，不改变部署时的计算图，即可为视频分支注入动作因果信息。它体现了"以信息架构代替损失函数惩罚"的思路：与其在训练结束后设法抑制泄漏，不如从注意力掩码层面直接定义哪些 token 可被谁看见，从而在根源上统一了世界模型的条件化学习与策略模型的无泄漏训练。

4. **自掩码作为"任务相关信号"的提炼**：将视觉预测从全 RGB 扩展到二值自掩码，本质上是把学习信号从"外观不变性"引导至"机器人本体运动"。这与人类操作学习中关注的"我的手在做什么"相呼应，既降低了视觉冗余对世界模型损失的稀释，又提升了在强场景随机化下的泛化稳健性。

5. **在超大规模数据上接近实用**：仅用 27.5K 仿真轨迹 + 17K 真实轨迹、单次训练 30 小时，即在 50 任务仿真基准上超越 π0.5、Motus、GigaWorld-Policy 与 FastWAM，且训练资源控制在 64 卡 A800，具备较强的可复现性。这对 WAM 类方法从"学术演示"走向"实验室内常规使用"是一个重要推动。

6. **附录与细节完备**（推测，基于正文结构）：论文提供了任务级成功率明细（表 S4）、真实数据收集与分割细节、评估协议说明等，有助于复现与基于置信度的细粒度分析。

## 8. 不足、局限与改进建议

1. **消融不完整**：只有"去掉自掩码"一组消融，缺少"去掉干净动作条件但保留自掩码"、"去掉动作条件且去掉自掩码但保留双任务训练"等组合，无法单独分离自掩码监督与动作条件化的贡献权重。未来可补充 2×2 全因子消融。
2. **自掩码监督机制细节有限**：9:1 采样比例的选择依据未给出，也未见比例敏感性分析；自掩码目标在动作分支是否产生间接梯度、以及在视频分支中的 loss 权重是否与 RGB 相同，均未明确。
3. **真实任务规模有限**：4 个放置类任务、每任务 10 次 trial 的统计功效较弱，结果置信区间宽泛；且未涉及力敏感、装配、插拔等高精度接触任务。建议在更多任务（尤其涉及夹爪与物体交互）上扩大试次量。
4. **长时程预测与语义泛化未验证**：评估的未来预测均为短期（秒级）rollout，对长时间跨度、未见过的指令组合或未见过的物体类别的泛化能力未进行系统检验。
5. **RoboSeg 分割误差传播未分析**：自掩码监督依赖离线分割质量，分割错误（尤其是运动模糊、遮挡、自遮挡下）如何影响训练目标与最终策略，没有定量分析。
6. **对比方法的公平性可再斟酌**：FastWAM 在同一训练数据上重新训练，但 π0、π0.5 等基线的训练数据、迭代轮数与硬件配置是否完全对齐，文中未完全披露；WorldArena 与 LPIPS 等指标是否对噪声种子敏感、是否多次重复测量，也未报告。

## 9. 与同类工作的定位关系

- **相对于 FastWAM**：FastWAM 是"速度优先"的世界动作模型，SelfWAM 保留其架构与推理高效性，但补上了"动作→未来"的条件化连接，属于同一技术路线上的因果一致性升级。
- **相对于 Motus / GigaWorld-Policy**：这两类方法更强调多模态世界模型联合训练或更大规模的视频生成预训练，SelfWAM 则强调"自接地"——未来预测必须绑定到本体动作上，而非仅仅是"可能发生什么"。
- **相对于 VLA（π0/π0.5）**：SelfWAM 延续了 VLA 的动作 token 化去噪训练框架，但在此基础上引入额外的世界模型目标，可看作 VLA 向"策略-世界一致性"方向的扩展。
- **与机器人基础模型（RBM）的关系**：SelfWAM 的训练数据规模远小于 RBM（数万级 vs 百万级），但其设计动机与 RBM 中"多模态动作条件世界模型"的目标一致，可被视作该方向上的一个高效、可复现的实例。

## 10. 总体评价

SelfWAM 的核心贡献不在于提出全新的模型家族，而在于以最小化架构改动将"动作接地（action grounding）"这一原则落到实处：它用一个干净动作副本和一个自掩码输出域，在不改变部署计算图的前提下，使视频预测从"观测条件式想象"变为"动作条件式因果推断"。这种方式既保留了大视频模型的生成先验，又使策略路径保持纯粹的动作去噪，体现了问题定义与工程实现之间较好的匹配度。

从实证角度看，SelfWAM 在 50 任务仿真基准上以 92.62% 的平均成功率刷新了 WAM 类方法的最优水平，在真实放置任务上平均 95% 成功率，同时动作推理延迟仅增加约 1%。这些结果足以支撑其核心论点：将世界模型的未来预测"动作条件化"不仅不损害策略效率，反而通过更精准的因果信号提升了策略的泛化与鲁棒性。

从方法论审美的角度看，SelfWAM 的优雅之处在于"用信息流约束代替额外的目标函数工程"——干净动作 token 的可见性由注意力掩码精确控制，动作监督与视觉监督在同一 flow-matching 框架下自然共存。这一设计使其具备较强的扩展潜力：原则上任何基于 token 化视频生成的世界模型都可以借鉴该非对称条件化模式。

当然，SelfWAM 的实验证据仍以短期、静态相机视角、pick-and-place 类任务为主，对动态交互、长时程任务和未见类别泛化的验证仍有不足。自我掩码监督对分割质量的依赖、以及 9:1 采样比例的选择也需要进一步敏感性分析。但整体上，这是一项定义清晰、方法简洁、实验扎实的工作，其"动作为世界的锚点"这一思想对未来机器人学习系统的设计具有实际参考价值。

**推荐引用场景**：需要为 VLA/WAM 类方法提供高效世界模型约束、或希望在不增加部署延迟的前提下引入视频预测目标的读者，可将 SelfWAM 作为首选对照与基础框架。

> 一句话收束：SelfWAM 用一次干净的注意力掩码调整，让世界模型"看见"了动作，也让机器人更从容地走向未来。
