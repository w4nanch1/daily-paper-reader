## 摘要
不同的研究路线以不同方式使用术语“世界模型”，但它们有一个共同目标：捕捉世界在动作作用下如何演变，以支持感知、模拟和规划。两个突出的实现是：在连续向量空间中学习动力学的神经预测器，以及暴露显式状态和物理定律的手工构建物理引擎。神经预测器从数据中扩展，但将动力学形式隐式化；物理引擎可检查和编辑，但难以大规模构建。我们引入VisualPatchWorld（VPW），它将世界动力学表示为代码。VPW首先通过短时主动探测选择定性动力学形式，然后通过最小化多步预测误差，从记录的状态-动作轨迹中拟合该形式的自由参数。得到的程序可以像模拟器一样向前滚动，以源代码形式检查，并用于模型预测控制；图像导出的场景图可以在重新规划时提供实时状态。与先前基于代码的世界模型相比，VPW实现了69.0%的平均规划成功率，超过最强代码基线23.5个百分点。最大的收益出现在需要选择正确定性动力学时。在同一规划器下，诱导模型在导航和丰富抓取控制上接近真实引擎的成功率；在接触丰富的推动任务中仍存在残差差距，而在引擎中检查少量有前景的计划可以弥合大部分差距。这些结果为自动构建对规划有用的代码世界模型建立了一条实用途径。代码见https://github.com/HKBU-KnowComp/VisualPatchWorld/。

## Abstract
Different research lines use the term world model in different ways, yet they share a common aim: to capture how the world evolves under action in a form that supports perception, simulation, and planning. Two prominent realizations are neural predictors that learn dynamics in continuous vector spaces, and hand-built physics engines that expose explicit state and physical laws. Neural predictors scale from data but leave the form of the dynamics implicit; physics engines are inspectable and editable but difficult to construct at scale. We introduce VisualPatchWorld (VPW), which represents world dynamics as code. VPW first selects a qualitative dynamical form with short active probes, then fits that form's free parameters from recorded state-action traces by minimizing multi-step prediction error. The resulting programs can be rolled forward like a simulator, inspected in source form, and used inside model-predictive control; image-derived scene graphs can supply the live state at replan time. Across comparisons with prior code-based world models, VPW attains 69.0% mean planning success and exceeds the strongest code baseline by 23.5 points. The largest gains arise when choosing the correct qualitative dynamics is essential. Under the same planner, the induced models approach ground-truth engine success on navigation and grasp-rich control; a residual gap remains for contact-rich pushing, and checking a shortlist of promising plans in the engine closes most of that gap. These results establish a practical route toward automatically constructed code world models that are useful for planning. Code is available at https://github.com/HKBU-KnowComp/VisualPatchWorld/.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：世界模型对于智能体的感知、模拟和规划至关重要。现有两大范式存在权衡：(1) **神经预测器**（如 Dreamer、LeWM）从数据中学习动力学，可扩展但隐式，无法检查或编辑；(2) **手工物理引擎**（如 MuJoCo）显式、可检查但难以大规模自动构建。
- **核心问题**：如何从交互轨迹中自动恢复 **模拟器风格** 的动力学，使其像物理引擎一样可执行、可检查、可编辑，同时又能从数据驱动的方式生成？
- **整体含义**：作者提出 VisualPatchWorld (VPW)，将世界动力学表示为 **可执行代码**，作为结构化潜在表示。这桥接了神经隐式模型与显式物理引擎，旨在为规划提供既具数据驱动可扩展性、又具备可解释性和可编辑性的世界模型。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：世界动力学建模为可执行的 Python 代码，而非神经网络权重。代码作为结构化潜在表示，可以被向前滚动、检查、编辑，并用于模型预测控制（MPC）。
- **技术路线**：分为 **四阶段**：
  - **Stage 1：视觉抽象**（Visual Abstraction）——将原始图像转化为结构化场景图（scene graph），包含物体姿态、关系（距离、接触标志、相对方向）。提供三种提取器：oracle（模拟器状态）、tool（计算机视觉启发式）、VLM（大视觉语言模型，用于语义基线）。
  - **Stage 2：轨迹导出**（Trajectory Export）——将交互轨迹转化为三元组 (场景图 $g_t$, 动作 $\tilde{a}_t$, 下一场景图 $g_{t+\delta}$)，形成用于程序归纳的符号转换记录。
  - **Stage 3：两级程序归纳**（Two-Level Program Induction）——核心创新：
    - **Level 1：草图选择**（Sketch Selection）——通过**主动探测**（active probing）在黑盒环境中运行短时 discriminative 实验，从一个小型候选家族（如接触力 vs. 自由运动、线性 vs. 非线性、抓取门控 vs. 始终耦合、关节空间 vs. 笛卡尔）中选择正确的定性动力学形式（dynamical sketch）。
    - **Level 2：参数拟合**（Parameter Identification）——将所选草图实例化为 Python 模板，通过**多步展开损失**（multi-step rollout loss）从离线状态-动作轨迹中拟合自由参数。使用多重启可微优化，最小化规划步长上的累积预测误差，避免单步误差低但长期漂移的问题。
  - **Stage 4：规划协议**（Planning Protocol）——使用重划界模型预测控制（CEM-MPC）进行闭环节控制。在每次重新规划时，可以通过图像场景图提供实时状态；评分模型可选：
    - **诱导评分**（Induced scoring）：仅用诱导的程序评分；
    - **混合评分**（Hybrid scoring）：用诱导模型评分所有候选，但用真实物理引擎（MuJoCo）重新评分前 30% 的短名单；
    - **模拟器评分**（Simulator scoring）：全部使用 MuJoCo，作为上限。
- **公式与算法**：文中给出了详细伪代码（Algorithm 1~6），涵盖场景图提取、轨迹导出、主动探测、多重启拟合、CEM-MPC 规划、完整端到端流程。主要特点是分离了结构选择与参数估计，通过主动探测消除了错误的定性形式。

## 6. 主要结论与发现

1. **两水平程序归纳有效**：先选择定性动力学草图，再拟合参数，比自由形式程序生成显著更好。VPW 在四个域平均规划成功率 **69.0%**，超过最强代码基线 POMDP-Coder (45.5%) 23.5 个百分点，比 PatchWorld (43.0%) 高 26 个百分点。
2. **结构选择是关键**：在 Reacher 上从 8% 提高到 72%，在 Cube 上达 86%，在 PushT 上从近 0% 提高到 22%（诱导评分）。最大增益来自正确选择定性动态形式的场景。
3. **诱导评分接近模拟器上限**：在导航（Two-room 96% vs 100%）和抓取（Cube 86% vs 94%）上接近 MuJoCo 天花板；在接触推动上差距较大（22% vs 96%）。
4. **混合评分（Hybrid）可弥合接触差距**：将诱导模型作为搜索引擎，对前 30% 候选使用 MuJoCo 重新评分，PushT 成功率从 22% 跃升至 88%（Tool）或 96%（Oracle），平均达 95.0%，接近 MuJoCo 上限 97.5%，同时大幅降低物理引擎查询次数（减少 70%）。
5. **代码世界模型是可编辑、可检查的规划接口**：诱导的程序可以像模拟器一样向前滚动，源代码形式可检查、可编辑，这为后续调试和泛化提供了基础。

## 7. 优点

- **方法论创新**：将世界模型构建为可执行代码，并采用 **两级归纳**（结构发现 + 参数拟合），解决了自由形式 LLM 生成容易错误定性的问题。主动探测是关键的 discriminative 步骤。
- **模块化设计**：视觉抽象与动力学分离，允许灵活使用 oracle / tool / VLM 提供状态，便于归因误差。
- **规划导向的拟合**：使用多步展开损失而非单步误差，使诱导模型更适合规划任务。
- **混合评分机制**：高效利用真实引擎验证候选，兼顾效率和精度。
- **实验全面、对比公平**：控制变量（训练数据、规划器、起始种子）、多种子验证、详细的感知与动力学消融。
- **代码与数据开源**：提供了可复现的实现，利于后续研究。

## 8. 不足与局限

- **需要手动定义草图家族**：每个环境需要提供一个小型定性动力学候选集，虽小但需要领域知识。未来工作应探索自动发现或更通用的草图库。
- **接触丰富任务仍有显著差距**：尤其是在推动任务（PushT）中，诱导评分仅 22%（Oracle），虽混合评分可弥补，但纯诱导模型尚不足以处理稀疏接触事件。
- **视觉抽象依赖工程化**：Tool 路径使用了颜色分割、PCA 朝向等启发式，非端到端学习；VLM 尚无法提供可靠的度量坐标。在更复杂视觉场景下可能失效。
- **仅测试仿真环境**：未涉及真实机器人部署，也未测试分布外泛化（如不同物体形状、不同物理参数）。
- **计算资源未公开**：未报告训练或优化所需 GPU 时长、型号等，影响复现成本评估。
- **规划器固定且针对各环境调参**：CEM 预算（样本数、迭代次数）是人工挑选使得 MuJoCo 成功率≥90%，这可能偏向有利于 VPW 的设定；但公平对比下基线也用相同规划器。
- **与神经世界模型的比较有限**：论文主要对比代码世界模型基线，神经参考仅作为难度参考，因为训练数据和范式不同（神经模型从像素端到端，VPW 从结构化状态），因此不能直接比较优劣。
