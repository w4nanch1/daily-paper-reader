## 摘要
许多近期的机器人策略试图通过使用大型预训练视觉-语言模型（VLM）作为动作骨干来追求更强的控制能力。我们引入了WorldDiT，一种统一的扩散Transformer架构，它将动作生成与视觉世界建模相结合，并且在没有大型预训练VLM动作骨干的情况下实现了强劲的性能。在训练过程中，一个单一的扩散Transformer生成连续的动作块，并从未来的相机帧中预测归一化的RGB补丁目标。在四个LIBERO模拟套件中，WorldDiT处于所有报告四个套件的方法中关于总模型参数和平均成功率所报告帕累托前沿之上。这些结果为未来的缩放研究提供了一个强大的亚十亿参数基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

## 2. 论文提出的方法论

### 核心思想
- 使用**单一的共享 DiT（Diffusion Transformer）骨干**联合建模连续机器人动作和未来相机帧的归一化 RGB patch，实现“世界-动作”统一建模。
- 与依赖大型 VLM 自回归生成动作 token 的世界-动作模型不同，WorldDiT 的**未来视觉预测仅作为训练时的辅助监督信号**，推理时完全不参与，保持动作专用的部署路径。

### 关键技术细节

**输入表征：**
- 观测窗口包含多视角 RGB 图像（主相机 + 腕部相机）、机器人状态和语言指令。
- 使用**冻结的 MAE 图像编码器**、共享的 **Perceiver Resampler**、**冻结的 CLIP 文本编码器**和**可训练的机器人状态编码器**，将多模态输入转化为 token 序列，条件化 DiT 骨干。

**动作与视觉目标：**
- 动作目标为 H 步连续动作块：\(A_i = [a_i, a_{i+1}, \dots, a_{i+H-1}] \in \mathbb{R}^{H \times d_a}\)，实验中 H=7，动作维度 d_a=7。
- 视觉目标：未来第 i+H 帧（主相机和腕部相机）经 CLIP 预处理后划分为 16×16 patches，每个 768 维 patch 向量用自身均值和方差归一化，每相机均匀保留 64 个 patch，共 128 个归一化 RGB patch 目标 token。
- 损失仅作用于最后一个时间槽（即 offset H 的视觉目标）。

**训练目标（Flow Matching）：**
- 对每个目标 y，定义从高斯噪声到干净目标的直线路径：\(x_\tau = (1-\tau)\epsilon + \tau y\)，其中 \(\tau \sim U[0,1]\)。
- 流匹配损失：\(\mathcal{L}_{\text{flow}} = \mathbb{E}_{\epsilon, y, \tau} \| v_\theta(x_\tau, \tau, c) - (y - \epsilon) \|_2^2\)。
- 总损失为动作流损失和 RGB patch 流损失的加权和：\(\mathcal{L}_{\text{total}} = w_{\text{action}} \mathcal{L}^{\text{action}}_{\text{flow}} + w_{\text{rgb}} \mathcal{L}^{\text{rgb}}_{\text{flow}}\)，权重分别为 0.1 和 0.001。

**模型配置：**
- DiT 骨干：深度 4、隐藏维度 1024、16 个注意力头、4 个 register tokens。
- 上下文 C=3 个观测步骤，动作块 H=7，完整训练窗口 N=10 步。

**推理流程：**
- 从高斯噪声初始化动作 token，用 20 步 Euler 积分数值求解动作速度场（\(\tau\) 从 0 到 1）。
- 执行预测动作块的前 3 个动作，更新上下文窗口，重新规划（receding-horizon control）。
- RGB patch 预测头和 token 完全排除在推理图之外。

## 7. 优点

- **架构设计的简洁性与统一性**：用单一的共享 DiT 骨干统一动作生成和世界建模，避免了大型 VLM 骨干带来的参数量爆炸。
- **训练-推理解耦的巧妙设计**：未来 RGB patch 预测只参与训练提供辅助监督，推理时完全移除，不增加部署负担。
